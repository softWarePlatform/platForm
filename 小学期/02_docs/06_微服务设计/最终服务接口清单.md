# D6 服务接口清单（最终版）

- 日期：2026-08-29
- 状态：最终评审版
- 外部兼容原则：前端继续访问 `/api/**`，由网关路由到目标服务
- 内部接口前缀：`/internal/**`，不得直接暴露给浏览器

## 1. 通用约定

| 项目 | 约定 |
| --- | --- |
| 身份传递 | 网关校验 JWT；向服务传递用户 ID、角色和 Request-ID。服务仍需做资源级授权 |
| 内部认证 | 服务身份令牌或 mTLS；只允许登记过的调用方 |
| 幂等 | 写通知、写错题及事件消费必须携带 `Idempotency-Key` |
| 超时 | 权限接口 1 秒；查询接口 2 秒；批量成绩接口 3 秒 |
| 错误格式 | `{ code, message, requestId, details? }` |
| 失败策略 | 权限依赖失败时拒绝访问；聚合依赖失败时返回部分结果并显式标识 unavailable，禁止静默按 0 计算 |
| 分页 | `page`、`pageSize`，响应包含 `items`、`total`、`page`、`pageSize` |

| 方法 | 路径 | 调用方 | 响应/用途 | 超时与失败 |
| --- | --- | --- | --- | --- |

| GET | `/internal/courses/:courseId` | homework、lab | `{ id, title, teacherId, published, semesterKey }` | 1 秒；404 表示课程不存在 |

| POST | `/internal/notifications` | homework、lab | 创建站内通知；必填幂等键 | 2 秒；失败写重试队列，不回滚核心事务 |
| POST | `/internal/dashboard/course-summaries:batch` | 网关聚合层 | 批量获取课程基本信息 | 2 秒；允许返回部分结果 |

## 7. 数据一致性与安全

1. 内部接口也必须检查调用方身份，不信任浏览器透传的角色字段。
2. 成绩服务对学生只统计并返回 `released=true` 的作业成绩。
3. 课程、用户或选课不存在时，作业/实验写接口必须失败，不允许先写后补权限。
4. 所有事件含 `eventId`；消费者保存去重记录，确保重复投递不重复写入。
5. 上传文件不在接口中暴露物理 `storedPath`；下载由归属服务鉴权后返回流或短期签名 URL。
6. 任何聚合接口都返回依赖状态，禁止把 unavailable 静默转换为 0 分或 0 人。
