## 3. 认证调用链

```mermaid
sequenceDiagram
  actor User
  participant Login
  participant Api as Axios api
  participant Auth as authRoutes
  participant Password
  participant JWT
  participant DB as Prisma/User
  participant Ctx as AuthProvider

  User->>Login: 输入邮箱和密码
  Login->>Api: POST /auth/login
  Api->>Auth: HTTP
  Auth->>DB: findUnique(email)
  Auth->>Password: verifyPassword
  Password-->>Auth: true/false
  Auth->>JWT: signToken
  Auth-->>Api: token + public user
  Login->>Ctx: setSession
  Ctx->>Ctx: 保存 State/localStorage
```

后续请求由 Axios 拦截器附加 token；`authRequired` 调 `verifyToken`，再校验角色。

## 6. UC06 自动评测调用链

```mermaid
sequenceDiagram
  actor Student
  participant Panel as LabSubmitPanel
  participant Route as labsRoutes
  participant Submit as lab-submit
  participant DB as Prisma
  participant Q as BullMQ
  participant W as JudgeWorker
  participant Run as CodeRunner

  Student->>Panel: 提交代码
  Panel->>Route: POST /labs/:id/submit
  Route->>Submit: load + assert + createCodeSubmission
  Submit->>DB: create Submission(PENDING)
  Submit->>Q: add {submissionId}
  Panel->>Route: 轮询 GET /submissions/:id
  Q->>W: 消费任务
  W->>DB: status=JUDGING + load TestCases
  loop 每个用例
    W->>Run: runCode(code,stdin,timeout)
    Run-->>W: stdout/stderr/exitCode/timedOut
  end
  W->>DB: 回写终态、score、resultJson
  Route-->>Panel: 脱敏反馈
```

## 8. UC09 成绩调用链

```mermaid
sequenceDiagram
  actor Teacher
  actor Student
  participant GP as GradebookPanel/CourseGrades
  participant R as gradesRoutes
  participant G as loadGradebook
  participant LG as lab-grades
  participant DB as Prisma

  Teacher->>R: PATCH grading-config
  R->>DB: 更新 Course 权重
  Teacher->>R: GET course gradebook
  R->>G: loadGradebook(courseId)
  G->>DB: Course + Enrollment + LabSet + Homework
  G->>DB: Submission + HomeworkSubmission
  G->>LG: bestScore / setAverage
  G->>G: homeworkAverage / total / rank / distribution
  R-->>GP: teacher gradebook
  Student->>R: GET /grades/me
  R->>G: 对每门已选课程 loadGradebook
  R-->>GP: 过滤当前学生后的课程汇总
```

当前学生视图与教师视图共用 `loadGradebook`，因此数值设计上一致；但也导致未发布作业分数进入学生汇总。

## 10. 继承、实现和依赖总结

| 关系 | 项目中的表现 |
| --- | --- |
| 继承 | 几乎没有业务继承；没有控制器/服务基类 |
| 接口实现 | 路由函数满足 `FastifyPluginAsync`；DTO/Props 满足 TS 结构类型 |
| 组合 | Fastify 注册路由插件；React 页面组合组件；Provider 包裹消费者 |
| 聚合 | `CourseContext` 聚合多域页面状态；`loadGradebook` 聚合多个成绩来源 |
| 依赖 | 路由依赖领域函数和 Prisma；组件依赖 Context/Hook/api |
| 关联 | Prisma relation 描述实体一对一、一对多和自关联 |

项目应继续优先使用组合而非人为引入继承层级。若微服务拆分后需要替换外部实现，可为课程访问、通知、实验成绩定义 Port 接口，再由 HTTP Adapter 实现。
