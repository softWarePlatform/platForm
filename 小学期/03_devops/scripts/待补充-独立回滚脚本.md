# 独立回滚脚本已补充

可执行脚本为 [`rollback-k8s.ps1`](rollback-k8s.ps1)。它接收目标镜像前缀和 40 位 Git SHA，将七个应用 Deployment 切换到 `sha-<GitSha>` 镜像，等待 rollout，并复用 `health-check.ps1` 生成恢复后的健康证据。

```powershell
./rollback-k8s.ps1 `
  -ImagePrefix "ghcr.io/<owner>/teaching-platform" `
  -GitSha "<目标版本的40位提交SHA>" `
  -EvidenceDirectory "test-results/rollback"
```

首次使用应加 `-WhatIf` 预演。回滚只处理应用镜像，不会逆向执行数据库 migration；数据库变更必须保持向后兼容。
