# 软件工程基础实践最终提交包

本目录按课程任务书整理，所有材料均从仓库现有文件**复制**而来；源码按要求未复制。

- `01_source`：原系统与微服务版本、提交记录和仓库清单；不含源码。
- `02_docs`：需求、设计、测试、追溯和模型文件。
- `03_devops`：容器、流水线、Kubernetes、数据库及部署材料。
- `04_tests`：测试代码、原始结果、流水线证据和压力测试脚本。
- `05_management`：已找到的站会、看板等管理材料。
- `06_defense`：现有答辩素材和备用演示材料。

本次已补齐根 README 环境/端口/启动/健康检查/测试账号与初始数据说明、独立 Kubernetes 回滚脚本、流水线归档说明与最终报告副本、三轮性能原始结果及分析、最终版测试计划。远程 GitHub Actions 的 URL/run ID 仍须由仓库管理员在最终推送运行后登记，不能由本地记录代替。
