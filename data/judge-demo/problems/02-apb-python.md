## 题目描述

从标准输入读入一行，包含两个整数 `a` 和 `b`（空格分隔），输出它们的和。

## 公开样例

| 输入 | 期望输出 |
|------|----------|
| `3 5` | `8` |

## 隐藏样例（评测有，界面不展示 I/O）

| 输入 | 期望输出 |
|------|----------|
| `10 20` | `30` |

## 题解

见 [`../solutions/ac/apb.py`](../solutions/ac/apb.py)

```python
a, b = map(int, input().split())
print(a + b)
```
