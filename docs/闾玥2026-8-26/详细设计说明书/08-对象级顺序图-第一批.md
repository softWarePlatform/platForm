- 任务：基于组件级顺序图细化到具体对象（类实例）之间的消息传递
- 用例总数：10
- 本批完成：**4/10 张**（达到总数 1/3 向上取整要求）
- 已完成：UC01、UC05、UC06、UC09
- 组件级输入：[`05-关键调用链与关系图.md`](./05-关键调用链与关系图.md)

## 1. 建模约定

- 参与者统一使用 `对象名:类名` 表示，例如 `enrollmentPage:EnrollmentPage`。
- React 函数组件、Fastify 路由插件和函数模块在对象图中按其运行期职责视为边界对象、控制对象和服务对象。
- Prisma 模型操作通过 `prisma:PrismaClient` 发出，并在消息中写明具体模型方法。
- `alt` 表示互斥业务分支，`opt` 表示可选流程，`loop` 表示循环，`par` 表示并行，`rect` 表示事务或异步处理边界。
- 返回消息使用虚线箭头；异常响应明确标出 HTTP 状态或领域错误。

## 2. UC01 对象级顺序图：学生选课、候补与课表同步

### 2.1 对象映射

| 对象实例 | 类/模块 | 类型 | 职责 |
| --- | --- | --- | --- |
| `student` | `User` | Actor/Entity | 发起选课的学生 |
| `enrollmentPage` | `EnrollmentPage` | Boundary | 收集教学班选择并刷新目录 |
| `api` | `AxiosInstance` | Gateway | 附加 JWT 并发送 HTTP 请求 |
| `enrollmentController` | `EnrollmentRoutes` | Control | 鉴权、Zod 校验、响应映射 |
| `enrollmentService` | `EnrollmentService` | Service | 选课窗口、重复、容量和候补规则 |
| `notificationService` | `RoleFeedbackService` | Service | 通知教师和管理员 |
| `prisma` | `PrismaClient` | Repository | 持久化课程、选课和日志 |

```mermaid
sequenceDiagram
  autonumber
  actor student as student:User
  participant page as enrollmentPage:EnrollmentPage
  participant api as api:AxiosInstance
  participant controller as enrollmentController:EnrollmentRoutes
  participant service as enrollmentService:EnrollmentService
  participant prisma as prisma:PrismaClient
  participant notify as notificationService:RoleFeedbackService

  student->>page: selectSection(courseId, classId)
  page->>api: post(/enrollment/courses/{courseId}/enroll, {classId})
  api->>controller: POST + Authorization Bearer token
  controller->>controller: authRequired(STUDENT, ADMIN)
  controller->>controller: enrollBodySchema.safeParse(body)

  alt JWT/角色或请求参数无效
    controller-->>api: HTTP 401/403/400 {error}
    api-->>page: reject(error)
    page-->>student: 显示错误提示
  else 校验通过
    controller->>service: enrollStudent(userId, courseId, {classId})
    service->>prisma: enrollmentPeriod.findUnique(semesterKey)
    prisma-->>service: period:EnrollmentPeriod
    service->>service: evaluateEnrollmentWindow(period)

    alt 选课阶段/时间窗关闭
      service-->>controller: throw 403 选课阶段已关闭
      controller-->>api: HTTP 403 {error}
    else 窗口开放
      service->>prisma: course.findUnique(courseId)
      prisma-->>service: course:Course + enrollments/classes
      service->>prisma: enrollment.findUnique(userId_courseId)
      prisma-->>service: existing:Enrollment|null

      alt 已选择该课程
        service-->>controller: throw 409 已选过该课程
        controller-->>api: HTTP 409 {error}
      else 未选且课程有容量
        rect rgb(238, 242, 255)
          Note over service,prisma: 选课核心写入
          service->>prisma: enrollment.create({userId,courseId,classId})
          prisma-->>service: enrollment:Enrollment
          service->>prisma: enrollmentLog.create(action=ENROLL)
          prisma-->>service: log:EnrollmentLog
        end
        service-->>controller: enrollment
        controller->>notify: notifyCourseStaffAndAdmins(courseId, actorUserId)
        notify->>prisma: siteNotification.createMany(...)
        controller-->>api: HTTP 200 {enrollment, ok:true}
        api-->>page: response
        par 刷新选课目录
          page->>api: GET /enrollment/catalog
        and 刷新个人课表
          page->>api: GET /dashboard/me
        end
        page-->>student: 显示“选课成功”及更新后课表
      else 课程已满
        service-->>controller: throw 409 课程人数已满
        controller-->>api: HTTP 409 {error}
        api-->>page: reject(error)
        student->>page: clickJoinWaitlist()
        page->>api: POST /enrollment/courses/{courseId}/waitlist
        api->>controller: waitlist request
        controller->>service: joinWaitlist(userId, courseId)
        service->>prisma: enrollmentWaitlist.create(...)
        service->>prisma: enrollmentLog.create(action=WAITLIST_JOIN)
        controller-->>api: HTTP 200 {ok:true}
        api-->>page: 候补成功
        page-->>student: 显示候补状态
      end
    end
  end
```

### 2.2 关键对象状态变化

`Enrollment` 从不存在变为已创建；`EnrollmentLog.action=ENROLL`。满员分支不创建 `Enrollment`，而创建 `EnrollmentWaitlist` 和 `WAITLIST_JOIN` 日志。

## 3. UC05 对象级顺序图：作业发布、提交、批改、发布与重做

### 3.1 对象映射

| 对象实例 | 类/模块 | 类型 | 职责 |
| --- | --- | --- | --- |
| `teacher`、`student` | `User` | Actor | 教师与学生 |
| `publishForm` | `HomeworkPublishForm` | Boundary | 创建作业 |
| `submitPanel` | `HomeworkStudentSubmit` | Boundary | 草稿、附件和正式提交 |
| `gradingPanel` | `HomeworkTeacherGradingPanel` | Boundary | 批改、发布成绩、处理重做 |
| `homeworkController` | `HomeworkRoutes` | Control | 作业主流程控制 |
| `studentController` | `HomeworkStudentRoutes` | Control | 草稿、附件和重做控制 |
| `settingsService` | `HomeworkSettingsService` | Service | 作业规则归一化 |
| `stateService` | `HomeworkStateService` | Service | 迟交、锁定、可提交状态 |
| `prisma` | `PrismaClient` | Repository | 作业聚合持久化 |

```mermaid
sequenceDiagram
  autonumber
  actor teacher as teacher:User
  actor student as student:User
  participant form as publishForm:HomeworkPublishForm
  participant submit as submitPanel:HomeworkStudentSubmit
  participant grade as gradingPanel:HomeworkTeacherGradingPanel
  participant api as api:AxiosInstance
  participant hc as homeworkController:HomeworkRoutes
  participant sc as studentController:HomeworkStudentRoutes
  participant settings as settingsService:HomeworkSettingsService
  participant state as stateService:HomeworkStateService
  participant prisma as prisma:PrismaClient

  teacher->>form: fillHomeworkRules()
  form->>api: POST /courses/{courseId}/homework
  api->>hc: create request
  hc->>hc: authRequired(TEACHER, ADMIN)
  hc->>settings: homeworkCreateSchema.safeParse(body)
  settings->>settings: normalizeHomeworkSettingsInput(data)
  settings-->>hc: normalizedData
  hc->>prisma: course.findUnique(courseId)
  prisma-->>hc: course:Course

  alt 非任课教师
    hc-->>api: HTTP 403 无权创建
  else 有权限
    rect rgb(238, 242, 255)
      hc->>prisma: homework.create(normalizedData)
      prisma-->>hc: homework:Homework
      hc->>prisma: homeworkRevision.create(snapshotJson)
    end
    hc-->>api: HTTP 200 {homework}
    api-->>form: 创建成功
  end

  student->>submit: editDraft(content)
  submit->>api: PUT /homework/{id}/draft
  api->>sc: save draft request
  sc->>prisma: homework.findUnique(id)
  sc->>sc: enrolledStudent(userId, role, courseId, teacherId)
  sc->>prisma: homeworkSubmission.upsert(draftContent)
  prisma-->>sc: submission:HomeworkSubmission
  sc-->>api: HTTP 200 {submission}

  student->>submit: clickFormalSubmit()
  submit->>api: POST /homework/{id}/submit
  api->>hc: submit request
  hc->>prisma: homework.findUnique(id + current submission)
  hc->>state: computeLateMeta(homework, now)
  state-->>hc: {isLate, lateDays, allowed}
  hc->>state: isSubmissionFinalized(submission)

  alt 截止且不允许迟交/提交已锁定
    hc-->>api: HTTP 400/403 {error}
    api-->>submit: 显示不可提交原因
  else 可以提交
    rect rgb(238, 242, 255)
      Note over hc,prisma: 正式提交事务
      hc->>prisma: homeworkSubmission.update(content, locked=true, submittedAt, isLate, lateDays)
      hc->>prisma: homeworkSubmissionVersion.create(version=n)
    end
    hc-->>api: HTTP 200 {submission, version}
    api-->>submit: 显示已提交/锁定
  end

  teacher->>grade: enterScore(rawScore, feedback)
  grade->>api: PATCH /homework/submissions/{sid}/grade
  api->>hc: grade request
  hc->>prisma: homeworkSubmission.findUnique(sid + homework)
  hc->>hc: assertHomeworkTeacher()
  opt 迟交扣分
    hc->>hc: finalScore=max(0, rawScore*(1-penaltyPercent*lateDays/100))
  end
  rect rgb(238, 242, 255)
    hc->>prisma: homeworkSubmission.update(score, feedback, graded=true)
    hc->>prisma: homeworkSubmissionVersion.update(latestVersion score/feedback/graded)
  end
  hc-->>api: HTTP 200 {submission}
  api-->>grade: 显示批改完成

  teacher->>grade: releaseGrades()
  grade->>api: PATCH /homework/{id}/release-grades
  api->>hc: release request
  hc->>prisma: homeworkSubmission.updateMany(released=true,releasedAt)
  hc->>prisma: homeworkSubmissionVersion.updateMany(released=true)
  hc->>prisma: siteNotification.createMany(...)
  hc-->>api: HTTP 200 {ok:true}
  api-->>grade: 成绩已发布

  opt 学生申请重做
    student->>submit: requestRedo(reason)
    submit->>api: POST /homework/{id}/redo-request
    api->>sc: create redo request
    sc->>state: remainingRedoCount(homework, submission)
    alt 不允许或次数耗尽
      sc-->>api: HTTP 400 {error}
    else 可申请
      sc->>prisma: homeworkRedoRequest.create(status=PENDING)
      sc-->>api: HTTP 200 {request}
      teacher->>grade: approveRedo(requestId)
      grade->>api: PATCH /homework/redo-requests/{rid}
      api->>sc: approve request
      rect rgb(238, 242, 255)
        sc->>prisma: homeworkRedoRequest.update(status=APPROVED)
        sc->>prisma: homeworkSubmission.update(locked=false, redoUsedCount+1)
      end
      sc-->>api: HTTP 200 {request, submission}
    end
  end
```

### 3.2 关键对象状态变化

`HomeworkSubmission` 经历草稿 → 正式提交/锁定 → 已批改 → 已发布；重做批准后重新解锁。每次正式提交形成一个不可替代的 `HomeworkSubmissionVersion`。

## 4. UC06 对象级顺序图：实验提交与 Worker 自动评测

### 4.1 对象映射

| 对象实例 | 类/模块 | 类型 | 职责 |
| --- | --- | --- | --- |
| `student` | `User` | Actor | 提交代码并查看结果 |
| `submitPanel` | `LabSubmitPanel` | Boundary | 发起提交并轮询状态 |
| `labController` | `LabRoutes` | Control | 鉴权、提交和反馈序列化 |
| `submitService` | `LabSubmitService` | Service | 时间窗、评测配置与提交创建 |
| `judgeQueue` | `Queue` | Queue | 保存 `submissionId` 任务 |
| `judgeWorker` | `JudgeWorker` | Worker | 消费任务并按用例计分 |
| `codeRunner` | `CodeRunner` | Service | 子进程执行 JS/Python |
| `prisma` | `PrismaClient` | Repository | 提交、实验和用例持久化 |

```mermaid
sequenceDiagram
  autonumber
  actor student as student:User
  participant panel as submitPanel:LabSubmitPanel
  participant api as api:AxiosInstance
  participant controller as labController:LabRoutes
  participant service as submitService:LabSubmitService
  participant prisma as prisma:PrismaClient
  participant queue as judgeQueue:Queue
  participant worker as judgeWorker:JudgeWorker
  participant runner as codeRunner:CodeRunner

  student->>panel: submitCode(language, code)
  panel->>api: POST /labs/{labId}/submit
  api->>controller: submit request + JWT
  controller->>controller: authRequired(STUDENT, TEACHER, ADMIN)
  controller->>service: loadLabForSubmit(labId)
  service->>prisma: lab.findUnique(labId + labSet + testCases)
  prisma-->>service: lab:Lab
  service->>service: resolveLabJudgeConfig(lab, labSet)
  service->>service: assertCanSubmitLab(user, labSet, now)

  alt 窗口外/语言不允许/文件类型不允许
    service-->>controller: throw 400/403 domain error
    controller-->>api: HTTP error {error}
    api-->>panel: 显示禁止提交原因
  else 可提交且 MANUAL 模式
    service->>prisma: submission.create(status=PENDING_REVIEW)
    prisma-->>service: submission:Submission
    service-->>controller: submission
    controller-->>api: HTTP 200 {submission}
    api-->>panel: 显示“待教师批改”
  else 可提交且 AUTO 模式
    service->>prisma: submission.create(status=PENDING)
    prisma-->>service: submission:Submission
    service->>queue: add(judge-submissions, {submissionId}, attempts=2)
    queue-->>service: job
    service-->>controller: submission
    controller-->>api: HTTP 200 {submission:PENDING}
    api-->>panel: 开始轮询

    par 前端轮询
      loop 每 800ms，最多 60s
        panel->>api: GET /submissions/{submissionId}
        api->>controller: query submission
        controller->>prisma: submission.findUnique(id)
        prisma-->>controller: currentSubmission
        controller-->>panel: status/score
      end
    and Worker 异步评测
      queue-->>worker: process({submissionId})
      worker->>prisma: submission.updateMany(status=JUDGING)
      worker->>prisma: submission.findUnique(include lab.testCases)
      prisma-->>worker: submission + lab + testCases

      alt 提交文件不可读
        worker->>prisma: submission.update(status=ERROR,resultJson)
      else 无测试用例
        worker->>prisma: submission.update(status=ACCEPTED,score=100)
      else 存在测试用例
        loop 按 testCase.id 顺序执行
          worker->>runner: runCode(language, code, input, timeoutMs)
          runner->>runner: create temp dir + spawn node/python3
          runner-->>worker: stdout, stderr, exitCode, timedOut
          alt timedOut
            worker->>prisma: update(status=TIMEOUT,partialScore)
          else exitCode != 0
            worker->>prisma: update(status=ERROR,partialScore,stderr)
          else 正常退出
            worker->>worker: normalizeOutput(stdout)==normalizeOutput(expected)
            worker->>worker: accumulate passedWeight
          end
        end
        worker->>worker: score=passedWeight/totalWeight*100
        worker->>prisma: update(ACCEPTED or WRONG_ANSWER,score,resultJson)
      end
    end

    controller->>controller: mask hidden test case details
    controller-->>panel: terminal status + sanitized feedback
    panel-->>student: 显示分数和公开用例结果
  end
```

### 4.2 关键对象状态变化

AUTO 提交状态为 `PENDING → JUDGING → ACCEPTED/WRONG_ANSWER/ERROR/TIMEOUT`；MANUAL 提交直接进入 `PENDING_REVIEW`，不入队。

## 5. UC09 对象级顺序图：权重配置、成绩汇总与学生查看

### 5.1 对象映射

| 对象实例 | 类/模块 | 类型 | 职责 |
| --- | --- | --- | --- |
| `teacher`、`student` | `User` | Actor | 配置/查看成绩 |
| `gradebookPanel` | `GradebookPanel` | Boundary | 教师权重和全班成绩册 |
| `courseGrades` | `CourseGrades` | Boundary | 学生课程成绩 |
| `gradeController` | `GradesRoutes` | Control | 权限、配置和响应 |
| `gradebookService` | `GradebookService` | Service | 聚合、总评、排名和分布 |
| `labGradeService` | `LabGradeService` | Service | 实验题最高分与实验集均分 |
| `prisma` | `PrismaClient` | Repository | 课程、名单、作业和实验成绩 |

```mermaid
sequenceDiagram
  autonumber
  actor teacher as teacher:User
  actor student as student:User
  participant panel as gradebookPanel:GradebookPanel
  participant studentView as courseGrades:CourseGrades
  participant api as api:AxiosInstance
  participant controller as gradeController:GradesRoutes
  participant service as gradebookService:GradebookService
  participant labGrade as labGradeService:LabGradeService
  participant prisma as prisma:PrismaClient

  teacher->>panel: setWeights(labWeight, homeworkWeight)
  panel->>api: PATCH /courses/{courseId}/grading-config
  api->>controller: config request
  controller->>controller: authRequired(TEACHER, ADMIN)
  controller->>controller: gradingConfigSchema.safeParse(body)
  controller->>controller: abs(labWeight+homeworkWeight-1)<=0.000001

  alt 范围非法或权重和不为 1
    controller-->>api: HTTP 400 {error}
    api-->>panel: 显示配置错误
  else 参数合法
    controller->>prisma: course.findUnique(courseId)
    prisma-->>controller: course:Course
    alt 非任课教师
      controller-->>api: HTTP 403 无权修改
    else 有权限
      controller->>prisma: course.update(labWeight, homeworkWeight)
      prisma-->>controller: updatedCourse
      controller-->>api: HTTP 200 {config}
      api-->>panel: 保存成功并 reload()
    end
  end

  teacher->>panel: openGradebook(courseId)
  panel->>api: GET /courses/{courseId}/gradebook
  api->>controller: teacher gradebook request
  controller->>service: loadGradebook(courseId)
  service->>prisma: course.findUnique(include enrollments,labSets,labs,homeworks)
  prisma-->>service: course aggregate
  service->>prisma: submission.findMany(studentIds,courseId)
  prisma-->>service: labSubmissions
  service->>prisma: homeworkSubmission.findMany(studentIds,courseId)
  prisma-->>service: homeworkSubmissions

  loop 每名选课学生
    loop 每个实验集
      loop 每道实验题
        service->>labGrade: bestScoreForLab(submissions,userId,labId)
        labGrade-->>service: bestScore|null
      end
      service->>labGrade: computeLabSetSetAverage(labIds,submissions,userId)
      labGrade-->>service: setAverage|null
    end
    service->>service: labAverage=mean(nonNull setAverage)
    service->>service: homeworkAverage=mean(graded nonNull score)
    service->>service: totalScore=(labAverage??0)*labWeight+(homeworkAverage??0)*homeworkWeight
  end
  service->>service: sort totalScore desc + assign rank
  service->>service: build distribution buckets
  service-->>controller: gradebookData
  controller-->>api: HTTP 200 {students,weights,distribution}
  api-->>panel: render teacher gradebook

  student->>studentView: openCourseGrades(courseId)
  studentView->>api: GET /grades/me
  api->>controller: student grades request
  controller->>prisma: enrollment.findMany(userId + courses)
  prisma-->>controller: enrollments
  loop 每门已选课程
    controller->>service: loadGradebook(courseId)
    service-->>controller: fullGradebook
    controller->>controller: find student where user.id==currentUserId
  end
  controller-->>api: HTTP 200 {courses:[own summaries]}
  api-->>studentView: 当前学生均分、总评、排名和权重
  studentView-->>student: 展示本人课程成绩

  Note over service,studentView: 当前实现会把 graded=true 但 released=false 的作业分数计入学生汇总，见 BUG-D1-LY-UC09-001
```

### 5.2 关键对象状态与一致性

教师和学生入口复用同一个 `gradebookService:GradebookService` 聚合结果，因此公式口径一致。学生响应只返回当前用户行；但发布状态过滤是当前实现的已知缺陷。
