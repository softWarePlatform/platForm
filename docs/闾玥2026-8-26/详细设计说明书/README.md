# 教学实训平台详细设计说明书

- 文档版本：1.0
- 基线日期：2026-08-26
- 代码基线：当前 `main` 单体版本
- 技术栈：React 19 + TypeScript、Fastify、Prisma/PostgreSQL、Redis/BullMQ、Judge Worker

## 1. 文档目标

本说明书回答以下问题：

1. 系统覆盖哪些业务用例，编号和责任边界是什么；
2. 系统由哪些模块构成，模块如何通信；
3. 关键“类”有哪些，其属性、方法和职责是什么；
4. 实体、控制器、领域函数、React 组件、Hook 之间如何调用；
5. 是否存在继承或接口实现关系；
6. 每个设计结论可以回溯到哪些源码文件。

本项目几乎不使用传统面向对象 `class`。本文将以下元素统一纳入“关键类设计”：

- Prisma Model：持久化实体类；
- Fastify 路由插件：控制器类；
- `backend/src/lib` 导出函数：领域服务类/策略类；
- TypeScript `type/interface`：DTO、值对象和接口；
- React 函数组件、Context、Hook：边界类、控制类和界面类；
- BullMQ Worker 与代码运行器：异步处理类。

## 3. 阅读顺序

首次阅读建议按 `01 → 02 → 03 → 04 → 05`。代码评审时可直接从 06 按领域定位源码。

## 4. 设计约定

- 前端公共请求基址为 `/api`，由 Axios 请求拦截器附加 JWT。
- 后端使用 Fastify 插件注册路由，以 Zod 校验输入，以 Prisma 访问 PostgreSQL。
- 授权由前端 `RequireRole` 提供导航保护，后端 `authRequired` 提供最终安全边界。
- 异步评测通过 BullMQ 队列 `judge-submissions`，Worker 按 `submissionId` 消费。
- 当前仍为单体；目标微服务边界为 `course-service`、`homework-grade-service`、`lab-practice-service`。
- 关系图中的“实现”表示满足框架类型契约，不表示 Java 风格的 `implements` 语法。

## 5. 维护规则

新增或修改用例时同步更新 01 和 05；新增 Prisma 模型或路由时更新 03；新增页面、Context 或核心组件时更新 04；任何文件更名都要更新 06 的源码索引。
