## 2. 用例详细追溯

### UC01 选课、退课、候补与课表

- 前置条件：用户已登录；课程已发布；当前选课窗口允许相应操作。
- 主流程：浏览目录 → 选择教学班 → `enrollStudent` → 写 `Enrollment` 和 `EnrollmentLog` → dashboard 读取课表。
- 备选流程：课程已满时 `joinWaitlist`；退课后 `promoteWaitlistForCourse` 自动晋升首位候补。
- 关键对象：`Course`、`Class`、`Enrollment`、`EnrollmentWaitlist`、`EnrollmentPeriod`、`EnrollmentLog`、`TimetableConfirmation`。
- 前端入口：`EnrollmentPage`、`Dashboard`、`WeeklySchedule`。
- 后端入口：`enrollmentRoutes`、`dashboardRoutes`；领域服务 `enrollment-service.ts`。

### UC02 创建、配置并发布课程

- 前置条件：教师或管理员登录。
- 主流程：提交课程信息和课表 → Zod 校验 → 创建 `Course` → 写 `COURSE_CREATE` 日志 → 更新/发布。
- 异常：课程代码冲突、空标题、越权操作、课表字段非法。
- 关键对象：`Course`、`Class`、`EnrollmentLog`、`ScheduleSlot`。
- 前端入口：`TeachingHub`、`CourseManage`、`CourseEnrollmentFields`、`CourseScheduleFields`。
- 后端入口：`coursesRoutes`；`course-enrollment-schema.ts`、`scheduleSlots.ts`。

### UC03 发布与阅读公告

- 主流程：教师创建公告 → 通知选课学生 → 学生读取详情 → upsert `AnnouncementRead`。
- 辅助流程：置顶、编辑历史、重要标记、未读统计。
- 关键对象：`CourseAnnouncement`、`AnnouncementRead`、`AnnouncementMark`、`SiteNotification`。
- 前端入口：`CourseAnnouncements`、`CourseAnnouncementDetail`。
- 后端入口：`announcementsRoutes`；`announcements.ts`。

### UC04 发布与获取资料

- 主流程：教师上传文件 → 保存文件与元数据 → 按可见范围过滤 → 学生下载/收藏。
- 关键规则：文件大小限制、扩展名分类、班级可见性、教师专属资料。
- 关键对象：`CourseMaterial`、`MaterialFavorite`、`Course`、`Class`。
- 前端入口：`CourseMaterials`、`MaterialsPanel`。
- 后端入口：`courseMaterialsRoutes`；`course-materials.ts`、`uploads.ts`。

### UC05 作业闭环

- 主流程：教师创建/发布 → 学生保存草稿/附件 → 正式提交并形成版本 → 教师批改 → 发布成绩。
- 备选流程：迟交扣分、教师打回、学生申请重做、审批后再次提交、AI 批改建议、知识薄弱点分析。
- 关键对象：`Homework`、`HomeworkAttachment`、`HomeworkRevision`、`HomeworkSubmission`、`HomeworkSubmissionVersion`、`HomeworkStudentFile`、`HomeworkRedoRequest`、`HomeworkKnowledgeAnalysis`、`HomeworkQuestion`。
- 前端入口：`CourseHomework`、`CourseHomeworkDetail`、`HomeworkStudentSubmit`、`HomeworkTeacherGradingPanel`。
- 后端入口：`homeworkRoutes`、`homeworkStudentRoutes`；`homework-settings.ts`、`homework-student.ts`。

### UC06 实验与自动评测

- 主流程：教师创建实验集/题目/用例 → 学生提交 → `createCodeSubmission` → BullMQ 入队 → Worker 运行代码 → 更新 `Submission`。
- 状态：`PENDING → JUDGING → ACCEPTED/WRONG_ANSWER/ERROR/TIMEOUT`；手工评测为 `PENDING_REVIEW`。
- 备选流程：文件提交、时间窗限制、手工批改、打回次数、补交。
- 关键对象：`LabSet`、`Lab`、`LabFile`、`TestCase`、`Submission`、`LabReminderSent`。
- 前端入口：`CourseLabs`、`LabSetManage`、`Lab`、`LabSubmitPanel`。
- 后端入口：`labSetsRoutes`、`labsRoutes`、`labFilesRoutes`；`lab-submit.ts`、`lab-set-status.ts`、Worker。

### UC07 练习、错题与辅导

- 主流程：选择模式/标签 → `pickQuestionsForSession` → 创建会话与题目项 → 保存答案 → `gradePracticeAnswer` → 更新统计与错题。
- 备选流程：SMART/BY_TAG/WRONG_BOOK/CUSTOM、代码题运行、题目反馈、文档导入、AI/模板辅导。
- 关键对象：`PracticeKnowledgeTag`、`PracticeQuestion`、`PracticeSession`、`PracticeSessionItem`、`PracticeQuestionFeedback`、`WrongBookEntry`。
- 前端入口：`CoursePractice`、`PracticeSession`、`PracticeTutorChat`。
- 后端入口：`practiceRoutes`；`practice-pick.ts`、`practice-grade.ts`、`practice-tutor.ts`。

### UC08 实验讨论与通知

- 主流程：创建讨论帖 → 解析提及用户 → 写帖子/评论/附件 → 创建通知 → 消息中心展示。
- 关键对象：`DiscussionPost`、`DiscussionComment`、`DiscussionAttachment`、`SiteNotification`。
- 前端入口：`LabDiscussionPanel`、`LabSetDiscussionPanel`、`MentionComposer`、`Messages`。
- 后端入口：`discussionsRoutes`、`notificationsRoutes`；`notification-events.ts`。

### UC09 综合成绩

- 主流程：教师配置权重 → `loadGradebook` 读取名单、实验和作业成绩 → 计算均分/总评/排名/分布 → 教师成绩册和学生视图展示。
- 关键对象：当前为 `Course.labWeight/homeworkWeight`、`LabSet`、`Lab`、`Submission`、`Homework`、`HomeworkSubmission`；目标新增 `GradingConfig`。
- 前端入口：`CourseGrades`、`GradebookPanel`、`MyHomework`。
- 后端入口：`gradesRoutes`；`lab-grades.ts`。
- 已知边界：未发布作业进入学生汇总、缺失分项按 0 加权、同分不并列；详见 UC09 验证记录。

### UC10 管理阶段、用户与日志

- 主流程：管理员配置 `EnrollmentPeriod` → 查看用户 → 特殊加退课 → 查看用户日志和管理员审计。
- 关键对象：`User`、`EnrollmentPeriod`、`EnrollmentLog`、`SiteNotification`。
- 前端入口：`AdminDashboard`、`AdminUsers`、`AdminUserLogs`、`AdminLogs`、`AdminClassServe`。
- 后端入口：`adminRoutes`、`enrollmentRoutes`、`authRoutes`。
- 已知缺口：无用户启用/禁用状态；删除用户使用通知而非独立审计表。

## 3. 用例—目标微服务映射

| 服务 | 用例 | 数据所有权 |
| --- | --- | --- |
| `course-service` | UC01—UC04、UC10 | 用户、课程、班级、选课、公告、资料、通知、管理配置 |
| `homework-grade-service` | UC05、UC09 | 作业、提交、批改、成绩配置与综合成绩 |
| `lab-practice-service` | UC06—UC08 | 实验、评测、练习、错题、讨论 |

## 4. 追溯规则

每个用例至少对应：一个前端入口、一个后端路由插件、一组领域函数、一组 Prisma 实体和一个测试编号前缀。测试前缀依次为 `TC-ENROLL/COURSE/ANN/MAT/HW/LAB/PRACTICE/DISCUSS/GRADE/ADMIN`。
