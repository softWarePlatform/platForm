> 本文档汇总本次实验管理相关改动的**功能、逻辑、页面、对应文件与测评方式**，供代码评审与联调验收使用。  
> 实现范围：步骤 1～8 已全部落地；步骤 9（管理页底部讨论）未做。

## 一、改动总览

| 模块 | 核心变化 |
| --- | --- |
| 实验集时间窗 | 开始/截止/补交/窗口外访问模式；统一状态机；进入与提交门禁 |

## 二、功能与逻辑详情

### 2.1 实验集时间窗与访问控制

**功能**

- `LabSet` 新增：`startAt`、`allowMakeup`、`makeupDueAt`、`outsideAccessMode`（`BLOCK` \| `VIEW_ONLY`）。
- 可提交窗口：`now ∈ [startAt, dueAt]` 或补交窗 `(dueAt, makeupDueAt]`（须 `allowMakeup`）。
- 未设 `startAt` 视为创建即可用；未设 `dueAt` 表示截止不限。
- 罚时起点改为 `startAt ?? createdAt`（与 `lab-set-penalty.ts` 同步）。

**状态机（服务端权威，`lab-set-status.ts`）**

| 角色 | 状态 | 条件 |
| --- | --- | --- |
| 教师 | 未开始 | `now < startAt`（或等效起点） |
| 教师 | 进行中 | 在正式窗口内 |
| 教师 | 补交中 | 已过 `dueAt` 且处于补交窗 |
| 教师 | 已截止 | 补交结束或未开放补交 |
| 学生 | 要补交 | 教师为补交中 **且** 集内未全部 AC |
| 学生 | 其他 | 与教师时间窗对齐（进行中/未开始/已截止） |

**访问控制**

- `BLOCK`：窗口外不可进入，提示「不在可访问时间内」。
- `VIEW_ONLY`：可看题面/讨论/AI，但 `POST submit-file` 返回 403。

**页面**

- `LabSetManage`：时间表单（开始/截止/补交/窗口外模式）。
- `LabSetHub`、`Lab`：`LabSetTimeBanner` 展示时间与状态。

**主要文件**

| 层级 | 路径 |
| --- | --- |
| 数据 | `backend/prisma/schema.prisma` |
| 迁移 | `backend/prisma/migrations/20260522140000_lab_set_time_window/` |
| 库 | `backend/src/lib/lab-set-status.ts`、`lab-set-penalty.ts` |
| 路由 | `backend/src/routes/lab-sets.ts`、`labs.ts` |
| 前端 | `frontend/src/features/labs/LabSetTimeBanner.tsx`、`labSetAccess.ts` |
| 页面 | `frontend/src/pages/LabSetManage.tsx`、`LabSetHub.tsx`、`Lab.tsx` |

### 2.2 实验集聚合列表（学生 / 教师）

**功能**

- **学生** `GET /lab-sets/mine/overview`：已选课程全部实验集。
- **教师** `GET /lab-sets/teaching/overview`：本人授课课程全部实验集。
- 卡片主体为 **实验集（LabSet）**，含课程名、时间、状态、进度或完成人数、得分（学生）。
- **完成**：集内每题均存在 `status === ACCEPTED` 的提交（与成绩册一致）。
- **得分**：`setAverage`（各题最高分均值）；未发布显示「—」。
- **教师完成人数**：集内全部 AC 的选课学生数 / 选课总人数。

**排序**

- 学生分组顺序：**要补交 > 进行中 > 未开始 > 已截止**；组内未完成优先，再按截止时间。
- 教师分组顺序：**补交中 > 进行中 > 未开始 > 已截止**；组内按截止时间。

**页面与导航**

| 入口 | 路由 | 说明 |
| --- | --- | --- |
| 顶栏「我的实验」 | `/my-labs` | 学生跨课程列表 |
| 顶栏「实验管理」 | `/teaching/labs` | 教师跨课程列表（在「作业批改」右侧） |
| 课程页「实验管理」 | 课程内 `CourseLabs` | 复用 `LabSetListPanel`，范围为本课 |
| 主界面快捷入口 | `Dashboard` | 我的实验 / 实验管理链接 |

**教师操作**：进入实验集、管理（`LabSetManage`）、删除（`DELETE .../lab-sets/:id`）。

### 2.3 文件提交、评测与手动批改

**功能**

- 提交形态：`Submission.submissionKind` = `CODE` \| `FILE`；文件字段 `fileName`、`fileStoredPath`、`language`。
- 实验集级配置：`judgeMode`（`AUTO` \| `MANUAL`）、`allowedFileExtensions`、`allowedLanguages`（题目可继承，空数组则继承集级）。
- 学生：选语言 → 上传文件 → 自动入队评测或 `PENDING_REVIEW`（手动）。
- 教师：点击学生行 → 弹窗展示每题 **最后一次提交**，可下载、手动打分/评语。
- 保留 `POST /labs/:id/submit`（代码）兼容旧数据；新流程主路径为 `POST /labs/:id/submit-file`。

**页面**

- `LabSubmitPanel`：样例、语言选择、上传、结果、「AI 分析」按钮。
- `LabSetManage`：批改模式与文件类型设置；`LabSetStudentSubmissionsModal`。
- `Lab`：右侧 Tab 区，无 Monaco 主编辑器。

### 2.4 单题页布局与讨论区

**布局**

- 左侧：Markdown 题面（`starterCode` 只读参考）。
- 右侧 Tab：**提交测评 / AI 助手 / 讨论区**。

**讨论区能力**

- 每题独立讨论（`DiscussionPost.labId`）；可选 `labSetId` 字段供扩展。

- @ 用户 → 写入 `SiteNotification`（类型 `DISCUSSION`）。
- 搜索（标题/内容/作者）、热门（浏览量 + 回复数）、帖子详情页与评论线程。
- 附件 API 已支持；**发帖弹窗暂无附件 UI**。
