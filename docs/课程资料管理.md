# 课程资料管理

### 教学大纲和相关文件

- 资料按文件夹/目录结构组织，支持多级目录（如“第1章/课件”“第1章/参考资料”）
- 支持文件类型：PDF、PPT、DOC、XLS、图片、视频、压缩包
- 单个文件大小限制：普通文件≤50MB，视频≤200MB（可配置）
- 教师端：
  - 支持上传、下载、删除、移动、重命名文件
  - 支持批量上传（拖拽/选择多个文件）
  - 支持设置资料可见范围（全班/指定班级/仅教师）
  - 支持置顶重要资料（显示在列表顶部）
  - 支持版本管理（更新同一资料时保留旧版本，学生可查看版本历史）
- 学生端：
  - 支持在线预览（PDF、图片、纯文本、代码文件）
  - 支持下载（单个/批量勾选打包下载）
  - 显示文件上传时间和上传者
  - 支持收藏重要资料，在“我的收藏”中快速访问
- 搜索功能：
  - 支持按文件名搜索（模糊匹配）
  - 支持按上传时间范围筛选
  - 支持按文件类型筛选（课件/视频/文档/代码）
  - 搜索结果高亮关键词
  - 教师端支持全文搜索（需提前建立索引，可选）
- 资料更新时，订阅该课程的用户收到通知（站内信/邮件可选）
- 资料访问统计（教师端）：查看每个文件的下载次数、最近下载时间
