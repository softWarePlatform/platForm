# UC01—UC04 缺陷记录

## BUG-D1-LI-001：创建课程返回 500，但课程记录已写入

| 项目 | 内容 |
| --- | --- |
| 关联用例 | UC02-M-01 |
| 建议优先级 | P1 |
| 状态 | 打开，待修复 |
| 复现日期 | 2026-08-25 |
| 复现环境 | PostgreSQL + 当前后端 API，`http://127.0.0.1:3000` |
| 复现稳定性 | 连续两次自动验证均复现 |

### 现象

教师调用 `POST /courses` 创建课程时，接口返回 HTTP 500：

```text
invalid input value for enum "EnrollmentLogAction": "COURSE_CREATE"
PostgreSQL error code: 22P02
```

接口失败后调用 `GET /courses/mine`，仍能查到刚刚创建的课程。这说明课程写入已提交，而随后的课程创建日志写入失败。

### 复现步骤

1. 使用 `teacher@demo.local` 登录并取得教师 token。
2. 调用 `POST /courses`，提交唯一 `courseCode`、合法标题、容量、学分和课表。
3. 观察响应为 HTTP 500。
4. 调用 `GET /courses/mine`。
5. 观察创建请求中的课程已经存在。

本次请求及完整错误响应保存在 [`evidence/uc01-uc04-api-results.json`](./evidence/uc01-uc04-api-results.json) 的 `UC02-create-course` 记录中。

### 预期与实际

| 项目 | 内容 |
| --- | --- |
| 预期 | 课程与创建日志一致写入，接口返回 HTTP 200；或任一步失败时全部回滚 |
| 实际 | `Course` 写入成功；`EnrollmentLog` 写入失败；接口返回 HTTP 500 |

### 根因证据

1. Prisma Schema 的 `EnrollmentLogAction` 包含 `COURSE_CREATE`。
2. `backend/prisma/migrations/20260517100000_enrollment_system/migration.sql` 创建枚举时只包含：`ENROLL`、`DROP`、`WAITLIST_JOIN`、`WAITLIST_LEAVE`、`WAITLIST_PROMOTED`、`ADMIN_ENROLL`、`ADMIN_DROP`、`TIMETABLE_CONFIRM`。
3. 当前 PostgreSQL 实际查询结果同样只有上述 8 个值，`databaseHasCourseCreate=false`。
4. `backend/src/routes/courses.ts` 先执行 `prisma.course.create()`，再单独执行 `prisma.enrollmentLog.create()`，两步没有放在同一个事务中。

因此，日志写入使用数据库不存在的枚举值而失败；由于课程写入已经提交，最终出现“响应失败但数据成功”的部分提交状态。

### 影响

- 教师在 UI 上会看到创建失败，无法确认课程是否创建成功。
- 用户重试时会因为 `courseCode` 已存在收到 HTTP 409。
- 数据库可能产生用户认为失败、实际已存在的课程记录。
- 创建课程与审计日志不一致，影响追踪和验收。

### 修复建议

1. 新增 Prisma 迁移，为 PostgreSQL 枚举补充 `COURSE_CREATE`，不要只修改 `schema.prisma`。
2. 将课程创建和 `EnrollmentLog` 创建放入同一个 `prisma.$transaction`，保证同时成功或同时回滚。
3. 生产或共享数据库执行迁移前先检查枚举值，确保迁移可重复部署。
4. 增加 UC02 自动化测试，明确断言接口状态、课程数量和日志记录。

迁移的核心 SQL 方向如下，实际应通过 Prisma migration 文件交付：

```sql
ALTER TYPE "EnrollmentLogAction"
ADD VALUE IF NOT EXISTS 'COURSE_CREATE';
```

### 回归标准

- [ ] 合法创建课程返回 HTTP 200。
- [ ] 返回体包含新课程，且 `published=false`。
- [ ] 数据库仅新增一条目标课程。
- [ ] `EnrollmentLog` 同步新增一条 `COURSE_CREATE` 记录。
- [ ] 日志写入失败时课程写入回滚。
- [ ] 重复 `courseCode` 仍返回 HTTP 409，且不新增课程。
- [ ] 重新执行 `uc01-uc04-verify.mjs` 后 23/23 通过。
