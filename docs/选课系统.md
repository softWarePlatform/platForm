## 选课系统（和主界面同步）

### 基本功能

- 学生端选课入口：课程中心 → 选课系统
- 展示当前学期所有可选的课程列表
- 每个课程卡片显示：课程名称、课程代码、学分、授课教师、上课时间、容量（已选/上限）、课程类别（必修/选修、数理课/英语课等分类）
- 选课操作：
  - 点击“选课”按钮，二次确认后加入个人课表
  - 若课程已满，显示“已满”并不可选，支持“候补”功能（有空位时自动通知）
  - 已选课程显示“退课”按钮，退课后释放名额
- 选课后主界面个人课表实时同步更新
- 选课时间控制：管理员可设置选课时间段（如第一周 08:00 至 第三周 23:59），非时间段内选课入口关闭

### 高级搜索

- 支持按以下字段组合搜索：
  - **课程名称**（模糊匹配，支持中文/英文）
  - **教师名称**（模糊匹配）
  - **班级名称**（如“计算机1班”）
  - **课程代码**（精确匹配）
- 搜索框支持自动补全（输入部分名称时下拉显示匹配项）
- 搜索结果实时刷新列表

### 课程类别筛选

- 按课程性质筛选：
  - 必修课 / 选修课
- 按学科分类筛选：
  - 数理课（高等数学、线性代数、概率论等）
  - 英语课（大学英语、专业英语等）
  - 计算机专业课（数据结构、操作系统等）
  - 思政课（马克思主义原理、近代史等）
  - 体育课
  - 通识选修课
- 支持多选类别（如同时筛选“必修+数理课”）
- 筛选后显示符合条件的课程数量

### 其他功能

- 预选课/正选/补退选阶段支持（管理员配置）
- 选课结果确认：选课结束后生成正式课表，学生需确认
- 选课日志：学生可查看自己的选课/退课操作历史
- 教师端：查看课程的选课学生名单，支持导出
- 管理员端：调整课程容量、修改课程信息、手动为学生加课/退课
