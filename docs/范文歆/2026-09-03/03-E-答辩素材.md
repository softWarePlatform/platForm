# E - 答辩素材（QA / 性能）

## 60 秒讲稿

我们没有把“单测通过”当作系统通过。质量验收从 Gateway 入口运行了 UC01 到 UC10 的真实端到端回归，覆盖 Course、Homework、Lab 的调用链，结果是 10 条全部通过。过程中 E2E 实际发现 Lab 向 Course 发中文通知幂等键会造成 HTTP 500；修复为 ASCII 安全的 SHA-256 key 后重新构建、滚动发布并全量复验通过。

云原生验证中，Gateway HPA 在负载下扩到两个 Ready Pod、稳定后收回一个；Judge Worker 停止时提交仍保存为 PENDING、其余服务保持 200，恢复 Worker 后同一提交最终 ACCEPTED、得分 100。性能方面已在等价隔离数据集上完成单体与微服务三轮对比，保留逐请求数据、P95、QPS、错误率和 Pod CPU/内存快照；三个接口的中位数错误率均为零，微服务在该本地测试条件下的中位 QPS 更高、P95 更低。

- 质量门：Course 5、Homework 25、Lab 44、Gateway 4，全部通过。
