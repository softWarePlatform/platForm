# 测试报告

---

## 1 引言

### 1.1 目标

本测试文档的目标是全面评估**在线教学与实训平台**（`teaching-platform`）的功能、性能、安全性、可用性和易用性，发现并记录系统中的缺陷和漏洞，为项目验收与后续维护提供依据。

### 1.2 背景

在线教学与实训平台面向高校师生，提供课程管理、选课、作业、编程实验自动评测、智能练习、资料管理、成绩统计、公告与通知等能力。平台按角色（学生 `STUDENT`、教师 `TEACHER`、管理员 `ADMIN`）提供差异化功能，并支持 AI 辅助（作业批改建议、实验辅导、练习识题与辅导）。

技术栈概览：

| 层次        | 技术                                          |
| --------- | ------------------------------------------- |
| 前端        | React 18 + Vite + TypeScript + React Router |
| 后端 API    | Fastify 5 + TypeScript + Zod 校验             |
| 数据层       | PostgreSQL + Prisma ORM                     |
| 缓存/队列     | Redis + BullMQ                              |
| 评测 Worker | `judge-worker`（独立进程，异步执行学生代码）               |
| 部署        | Docker Compose + Nginx（本地验证）；Kubernetes + GitHub Actions CI/CD（`k8s/monolith`，见 `docs/GitHub-Actions流水线配置.md`） |

测试目的：

1. **验证功能实现**：选课、课表、作业发布/提交/批改、实验集与自动评测、练习组卷、资料上传、成绩汇总等按需求正常运行。
2. **用户体验保障**：主界面、课程 Tab、教学台等交互流畅、信息清晰。
3. **隐私及安全性**：JWT 认证、角色权限、密码哈希、限流与安全响应头有效。
4. **稳定性和性能**：健康检查、冒烟压测、评测队列解耦下系统可稳定运行。
5. **发现并修复缺陷**：记录问题并回归验证。

### 1.3 范围

本报告适用于平台全部主要模块：

* **功能测试**
  * **主界面与课表**：周视图课表、课程分类卡片、搜索、个性签名（`docs/主界面.md`）
  * **选课系统**：目录浏览、多维筛选、选课/退课/候补、课表确认（`docs/选课系统.md`）
  * **课程管理**：教师创建/发布课程、课表时段、选课字段（`backend/src/routes/courses.ts`）
  * **课程公告**：发布、已读标记（`docs/课程公告.md`）
  * **作业管理**：发布、迟交/重做规则、学生提交、批改、错题本（`docs/作业管理.md`）
  * **实验管理**：实验集时间窗、题目 CRUD、代码提交、Redis 评测队列、讨论区（`docs/实验管理.md`）
  * **练习模块**：题库、标签、智能/按标签/错题/自定义组卷、AI 辅导（`docs/练习.md`）
  * **课程资料**：上传、下载、分类（`docs/课程资料管理.md`）
  * **成绩统计**：权重配置、成绩册导出（`docs/成绩统计.md`）
  * **用户与权限**：注册、登录、个人资料、改密、邮箱验证流程
  * **通知**：站内信、未读计数
  * **管理端**：用户管理、选课期配置（`/admin` 路由）
* **安全性测试**：认证授权、输入校验、SQL 注入/XSS 基础防护、速率限制
* **易用性测试**：界面布局、操作步骤、错误提示
* **兼容性测试**：Chrome、Edge、Firefox 等主流浏览器
* **性能测试**：`/health/ready` 冒烟压测（`npm run perf:smoke`）

不在本次范围：公网生产级代码沙箱隔离（见 `RUN.txt` 安全提示）、多语言国际化。

#### 风险

1. **时间风险**：一天内难以覆盖全部边界用例。
2. **环境风险**：PostgreSQL / Redis / Worker 未启动导致实验评测失败。
3. **数据风险**：边界场景（满课、迟交、未开始实验集等）依赖 `seed-skipped-test-cases` 固定 fixture；未 seed 时相关用例无法执行。
4. **AI 功能风险**：未配置 `OPENAI_API_KEY` 时 AI 路由降级为本地模板，需单独标注测试结论。

### 7.2 性能测试结论

TC-PERF-001（50 并发 × 500 请求）**满足** 2.4 节准则：成功率 **100%**（500/500），吞吐 **≈806 req/s**，耗时 620 ms。TC-PERF-002（100×2000）成功率仅 **30%**（600/2000），原因为 Fastify 全局限流 `RATE_LIMIT_MAX=600`/min，超额请求返回 **429**；峰值吞吐约 **1628 req/s**。冒烟场景通过，极端压测需调整限流配置后复测。

### 7.3 安全性测试结论

平台采用 JWT Bearer 认证、bcrypt 密码哈希、Fastify helmet 与全局 rate-limit。抽检结果：**4/4 通过**。SQL 注入片段经 Prisma 参数化查询返回空结果且无 500；XSS 载荷可写入公告但前端 React 转义；响应头含 nosniff、frame-options 等 helmet 头；越权与未登录访问分别返回 403/401。

### 7.4 兼容性测试结论

**Chrome**：P0 链路 **UI 实测通过**，`docs/figures/` 含登录、选课、课程、实验等 16 张截图（见 6.3.1、6.6.1）。
