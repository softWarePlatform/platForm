# 04 前端关键组件与类型设计

## 1. 前端对象模型

前端采用 React 函数组件。组件的“属性”是 Props、State、Context 值和 Memo 值；“方法”是组件内部回调、Hook 和事件处理器。

## 2. 应用级控制类

### `App`

- 责任：声明全部路由和角色边界。
- 方法：函数组件 `App()`。
- 组合：`Shell`、三套角色课程路由、教学台、学生页、管理后台。
- 安全辅助：`RequireAuth` 检查 token；`RequireRole` 检查 `User.role`。
- 关系：实现 React `FunctionComponent` 约定；组合 React Router `Routes/Route/Navigate`。

### `AuthProvider` / `AuthContext`

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `user` | `User|null` | 当前用户：id、email、name、role、头像、签名、验证状态 |
| `token` | `string|null` | JWT |
| `setSession` | function | 同步 React State 与 localStorage |
| `logout` | function | 清理会话和存储 |
| `profileFetchGen` | ref number | 防止旧 `/auth/me` 请求覆盖新会话 |

方法：`readStored`、`AuthProvider`、`useAuth`。Provider 在 token 变化后调用 `/auth/me` 刷新用户资料。

### `api`

- 类型：AxiosInstance。
- 属性：`baseURL=/api`。
- 请求方法：从 localStorage 读取 token 并写 `Authorization`。
- 响应方法：收到 401 时清除会话并跳转 `/login`。

### `CourseProvider` / `CourseContext`

| 属性组 | 内容 |
| --- | --- |
| 身份与课程 | `courseId,course,user,token,isTeacher,isEnrolled` |
| 领域集合 | `labs,labSets,homework,posts,materials` |
| 作业编辑状态 | `hwForm,hwDrafts,hwSubmissions,hwGradeDrafts,hwAiPreview,hwAiBusy` |
| 讨论状态 | `newPost` |
| 方法 | `refreshSideData,enroll,setErr` 及各 setState |

调用关系：`CourseLayout` 提供 Context；课程各 Tab 调 `useCourse()`；Provider 用 `Promise.all` 聚合课程、实验、作业、讨论、资料和实验集。

## 5. Hook 与工具类

| Hook/工具 | 属性/输入 | 方法/输出 |
| --- | --- | --- |
| `useAuth` | 无 | 返回 `AuthState`，要求位于 `AuthProvider` 内 |
| `useCourse` | 无 | 返回 `CourseContextValue`，要求位于 `CourseProvider` 内 |
| `useLabSetOverview` | 角色/筛选 | 请求实验总览并返回加载状态 |
| `useLabSetMyProgress` | `courseId,labSetId` | 返回题目进度、错误、刷新方法 |
| `useSubmit` | async action | 管理 submitting/error |
| `usePagination` | items/page size | 当前页、总页数、切页方法 |
| `scheduleStorage` | userId | localStorage 读写自定义课表和课程顺序 |
| `mentionUtils` | 文本、成员 | 解析、合并提及 ID |
| `practiceTagFilter` | tagPath/filter/mode | 判断标签层级关系 |

## 7. 继承与接口关系结论

- React 组件不继承 `React.Component`，全部为函数组件。
- Props 和 DTO 通过 TypeScript 结构类型满足接口；部分类型使用 `Omit`、`Pick`、交叉类型扩展。
- Context Provider 与消费者是组合/依赖关系。
- 页面通过 React Router `Outlet` 组合，不是继承。
- 功能复用主要通过 Hook、纯函数和组件组合完成。
