1. 内部调用只使用 `x-internal-service-token`；浏览器身份与浏览器传入角色均不可信。

5. C 的代码已经过契约复核；真实联调前仍需使用 `docs/胡思琪/2026-09-02/02-A-course-service-内部接口与验收.md` 的环境变量和错误语义进行一次进程级验证。
