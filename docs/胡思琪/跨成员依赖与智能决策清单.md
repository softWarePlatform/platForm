## 固定交互规则

1. 内部调用只使用 `x-internal-service-token`；浏览器身份与浏览器传入角色均不可信。
2. 课程权限和成员名单只能通过课程服务 `/internal/**` 获取，B/C 不读取 `course_service`。
3. Dashboard 当前调用 C 的 `GET /internal/courses/:courseId/homework-summary`；B 的 Dashboard 摘要接口仍未冻结。所有调用均传递 `x-request-id`。
4. 上游不可用是“未知”，不是 `0`；前端应显示服务暂不可用。
5. A 的契约测试已通过；真实联调前仍需使用 `docs/胡思琪/2026-09-02/02-A-course-service-内部接口与验收.md` 的环境变量和错误语义进行一次进程级验证。
