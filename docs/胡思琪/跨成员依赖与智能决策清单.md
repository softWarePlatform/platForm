## 固定交互规则

1. 内部调用只使用 `x-internal-service-token`；浏览器身份与浏览器传入角色均不可信。
2. 课程权限和成员名单只能通过课程服务 `/internal/**` 获取，B/C 不读取 `course_service`。
3. Dashboard 上游调用使用 `POST /internal/dashboard/course-summaries:batch`，每次至多 100 门课程；调用方必须转发 `x-request-id`。
4. 上游不可用是“未知”，不是 `0`；前端应显示服务暂不可用。
5. 真实联调前，B/C 先用 `docs/胡思琪/2026-09-02/02-A-course-service-内部接口与验收.md` 中的契约进行桩测试。
