## 2. 通用规则

学生、教师和管理员均须登录。课程级操作须满足课程教师、管理员或有效选课关系；未登录、越权和无课程访问资格的请求必须被拒绝。通知服务负责公告、讨论、打回等事件的站内通知与未读状态；AI 服务不可用时允许降级为本地模板，但不得影响主业务记录或泄露受限数据。

## 3. 用例需求说明

### REQ01 / UC01 完成选课、退课或候补并同步课表

- 参与者：学生；次要参与者为管理员、教师。
- 触发与前置：学生在允许操作的选课阶段对已发布课程选择选课、退课或候补；已登录。
- 主成功流程：查看目录和本人状态 → 筛选课程并查看容量、时段 → 系统校验阶段、重复、容量和时间冲突 → 创建选课记录并占用名额 → 更新学生课程、教师名单和个人课表。
- 备选/异常：满课时按规则加入候补，出现空位后按顺序递补；退课释放名额并移除课表，可触发候补递补；窗口关闭、课程未发布、重复选课或时间冲突时拒绝。
- 可验证结果：选课、候补、容量、成员名单与 `/dashboard/me` 课表一致；异常路径不得创建正式选课记录。

### REQ02 / UC02 创建、配置并发布课程

- 参与者：教师；次要参与者为管理员、学生。
- 触发与前置：教师需要新建课程并向学生开放；教师已登录且具有课程管理权限。
- 主成功流程：填写名称、代码、描述和学期信息 → 配置课程性质、容量、课表和地点 → 校验必填项与代码唯一性后创建草稿 → 教师确认配置并发布 → 已发布课程进入学生课程目录。
- 备选/异常：代码重复或字段非法时拒绝；无权用户不可修改或发布；未发布或取消发布的课程不向普通学生开放；删除有关联数据的课程必须受控处理。
- 可验证结果：教师可查询到完整配置；发布课程学生可见，未发布课程学生不可见；课程代码唯一。

### REQ03 / UC03 发布并阅读课程公告

- 参与者：教师、学生；次要参与者为通知服务。
- 触发与前置：教师向所管理课程发布公告；学生已选课。
- 主成功流程：教师填写标题、正文和置顶状态 → 系统保存并按置顶/发布时间排序 → 为课程成员生成通知和未读记录 → 学生从列表或通知打开详情 → 系统记录阅读并更新未读数。
- 备选/异常：教师可编辑或删除；非课程成员不可读取；非课程教师不可发布；通知失败不能丢失公告主体，且应可诊断。
- 可验证结果：公告内容、排序、通知、阅读记录和未读数一致；编辑、删除和权限结果正确。

### REQ04 / UC04 发布并获取课程资料

- 参与者：教师、学生；次要参与者为文件存储模块。
- 触发与前置：教师上传资料，或学生浏览、收藏、下载资料；教师管理课程，学生有课程访问资格，文件符合限制。
- 主成功流程：教师上传文件并填写名称/说明 → 系统校验并保存文件和元数据 → 学生查看资料列表 → 浏览或下载正确内容 → 收藏资料以便再次访问。
- 备选/异常：教师可更新、移动或删除资料；文件超限、参数不完整或存储失败时不保留无效元数据；无权访问、文件已删除或物理缺失时返回明确错误。
- 可验证结果：列表元数据、收藏和下载内容正确；超限文件与无权访问均被拒绝且无残留数据。

### REQ05 / UC05 完成作业发布、提交、批改和重做

- 参与者：教师、学生；次要参与者为通知服务、AI 服务或本地降级模块。
- 触发与前置：教师布置作业，学生完成并提交；课程权限、时间、迟交和重做规则已配置。
- 主成功流程：教师发布作业 → 学生查看要求并保存草稿 → 正式提交并记录版本、时间、迟交状态 → 教师评分和评语 → 发布成绩 → 学生查看结果；规则允许时可申请并获批重做。
- 备选/异常：允许迟交时标识迟交并应用规则，否则拒绝；教师可打回并写明原因；正式提交后按规则限制修改；非法分数、越权或超过重做次数时拒绝；AI 不可用不影响成绩主流程。
- 可验证结果：学生端、教师端和完成统计中的状态一致；提交版本、评分、发布、迟交、打回和重做历史可追溯。

### REQ06 / UC06 完成实验发布、提交和自动评测

- 参与者：教师、学生、评测 Worker；次要参与者为 Redis 队列、通知服务、AI 服务或本地降级模块。
- 触发与前置：教师发布实验；学生提交代码；实验题、用例与时间窗已配置，自动模式下数据库和 Redis 可用。
- 主成功流程：教师配置实验集、题目、语言和公开/隐藏用例 → 学生提交代码 → API 保存 `PENDING` 提交并投递任务 → Worker 领取任务、评测并写回终态、得分和反馈 → 学生查看脱敏结果，教师查看统计。
- 备选/异常：时间窗外或不符合语言/文件规则时拒绝；手动评测进入 `PENDING_REVIEW`；编译/运行错误、超时和答案错误有明确分类；Worker 不可用时保持待评测；打回和补交遵守次数与时间规则。
- 可验证结果：状态遵循“等待评测—评测中—终态”；得分与用例权重一致；隐藏用例细节只对授权角色可见。

### REQ07 / UC07 完成练习组卷、答题和错题反馈

- 参与者：学生；次要参与者为教师、AI 服务或本地降级模块。
- 触发与前置：学生以智能、知识点、错题或自定义模式练习；已登录并有课程权限，题库存在可用题目。
- 主成功流程：选择模式和筛选条件 → 系统创建包含题目的练习会话 → 学生逐题作答并保存 → 提交会话 → 系统判分并返回解析 → 错题纳入后续练习范围 → 学生可请求提示、相似题或提交反馈。
- 备选/异常：题目不足时提示或按规则缩减题量，不能创建空会话；未答题按规则提示确认或保留未答；AI 不可用时使用本地模板；题库管理和反馈处理仅教师/管理员可执行。
- 可验证结果：会话题目、答案、逐题结果、总分和错题范围一致；提示不直接改写正式答案或成绩。

### REQ08 / UC08 参与实验讨论并接收提醒

- 参与者：学生、教师；次要参与者为通知服务。
- 触发与前置：课程成员对课程、实验集或实验题发布帖子、回复或提及成员；已登录且有对应访问资格。
- 主成功流程：进入讨论区 → 发布帖子及附件 → 成员查看并评论/回复 → 提及成员时生成通知 → 被提及者从通知打开讨论并更新已读 → 作者或教师标记已解决。
- 备选/异常：作者可管理自己的内容，教师可处理不当内容；非成员不可读写；无效附件或提及对象被拒绝；通知不可用时讨论正文保持一致并保留可诊断信息。
- 可验证结果：讨论按课程/实验范围归档；回复、附件、提及、通知、已读和已解决状态一致。

### REQ09 / UC09 配置并查看课程综合成绩

- 参与者：教师、学生；次要参与者为作业和实验模块。
- 触发与前置：教师配置或查看课程成绩，学生查看个人成绩；课程、选课关系和可计分结果存在。
- 主成功流程：教师查看并设置作业/实验权重 → 系统校验范围及总和 → 聚合已发布作业成绩、实验最高分和实验集均分 → 计算总评、排名和分布 → 教师查看或导出成绩册 → 学生查看本人分项、权重、总评和排名。
- 备选/异常：权重非法时保留原配置；未批改或未发布成绩显示为空或不计入，不得伪造为零分；学生仅看本人，教师仅管理有权课程。
- 可验证结果：教师成绩册、学生个人成绩和导出数据公式一致；非法权重、越权查询被拒绝。

> 当前对象级设计记录了已知实现偏差 `BUG-D1-LY-UC09-001`：`graded=true` 且 `released=false` 的作业分数目前会进入学生汇总。该行为不符合本需求的“仅已发布作业成绩面向学生”的验收口径，必须在验收前修正或明确为已知限制。

### REQ10 / UC10 管理选课阶段、用户和操作记录

- 参与者：管理员；次要参与者为学生、教师。
- 触发与前置：管理员维护选课运行阶段、用户或审计记录；已登录并通过管理员权限校验。
- 主成功流程：查看平台概况 → 配置选课阶段、开放/关闭时间和规则 → 保存后使学生端状态生效 → 查询用户和操作记录 → 按约束执行用户管理 → 系统形成可审计记录。
- 备选/异常：非管理员访问被拒绝；无效阶段或时间范围不可保存；处理具有关联教学数据的用户需拒绝或受控清理；无审计记录返回空结果，故障不得泄露其他用户信息。
- 可验证结果：`/enrollment/status` 与实际允许的选课操作一致；管理员可查授权范围用户与审计；非管理员得到拒绝或前端重定向。

## 4. 验收与变更规则

每个 REQ/UC 必须至少关联一条主流程测试和一条异常或权限测试，并能关联设计模型、代码模块和可复查证据。编号一经基线确认不得复用；需求语义变更须新建版本记录，设计和测试仍沿用同一 REQ 编号进行回归追溯。
