## 1. 文档目的与范围

本说明书定义学生、教师、管理员和评测 Worker 在在线教学与实训平台中的可验收业务流程。范围覆盖课程运行、选课、教学内容、作业、实验、练习、讨论、成绩和平台管理；不把单一页面、按钮或纯技术接口作为独立业务用例。

本版是需求说明初稿：UC01—UC04 已有 2026-08-25 API 验证记录，其余用例的文字范围已依据现有实现整理，仍须按后续测试计划补齐专项证据。

## 2. 参与者与通用业务规则

| 参与者       | 业务职责                                   |
| --------- | -------------------------------------- |
| 学生        | 选课并学习课程，提交作业和实验，完成练习，参与讨论，查看本人通知与成绩。   |
| 教师        | 创建和维护本人课程，发布公告、资料、作业、实验与练习题，批改并查看教学统计。 |
| 管理员       | 维护选课阶段、用户、班级与平台运行记录，按管理权限查看教学运行数据。     |
| 评测 Worker | 消费实验自动评测任务，执行测试并将状态、分数和反馈写回平台。         |

通用规则：用户须登录；课程级操作须满足课程教师身份、管理员身份或有效选课关系。无登录状态应提示登录，角色或课程访问不满足时应拒绝操作；所有涉及时间窗、容量、分数和状态的规则由系统校验，前端提示不替代服务端判断。

## 4. 用例需求说明

### UC01 完成选课、退课或候补并同步课表

| 项目      | 说明                                                                                     |
| ------- | -------------------------------------------------------------------------------------- |
| 参与者     | 学生；管理员负责配置选课阶段。                                                                        |
| 触发条件    | 学生在选课目录选择课程并执行选课、退课或候补操作。                                                              |
| 前置条件    | 学生已登录；目标课程存在；选课阶段开放。                                                                   |
| 主成功流程   | 1. 学生查看选课窗口与课程目录。2. 选择未满课程。3. 系统校验阶段、重复选课和课程容量。4. 系统建立选课记录。5. 学生在课程列表和个人课表中看到该课程及排课时段。 |
| 备选/异常流程 | 课程已满时，直接选课失败且学生可申请候补；重复选课或重复候补时拒绝；未选课时退课被拒绝；窗口关闭时不允许选课。                                |
| 可验证结果   | 选课、退课或候补状态正确；个人课表与课程列表同步；异常情况具有明确结果。                                                   |

### UC02 创建、配置并发布课程

| 项目      | 说明                                                                                                     |
| ------- | ------------------------------------------------------------------------------------------------------ |
| 参与者     | 教师。                                                                                                    |
| 触发条件    | 教师在教学端新建课程或更新课程配置并发布。                                                                                  |
| 前置条件    | 教师已登录；课程代码未被占用。                                                                                        |
| 主成功流程   | 1. 教师填写课程名称、代码、容量、学分等信息。2. 系统校验必填项和唯一课程代码。3. 系统创建课程并记录创建操作。4. 教师配置课表、容量等信息。5. 教师发布课程。6. 学生可从公开目录检索该课程。 |
| 备选/异常流程 | 重复课程代码、空标题等不合法输入被拒绝；学生或非课程教师不能创建、修改或发布课程。                                                              |
| 可验证结果   | 课程信息和创建记录保存正确；发布状态使课程出现在公开目录；权限和输入校验有效。                                                                |

### UC03 发布并阅读课程公告

| 项目      | 说明                                                                           |
| ------- | ---------------------------------------------------------------------------- |
| 参与者     | 教师、学生。                                                                       |
| 触发条件    | 教师发布课程公告，或学生打开公告列表、详情。                                                       |
| 前置条件    | 教师是课程负责人；学生已选课。                                                              |
| 主成功流程   | 1. 教师填写标题和正文并发布。2. 系统保存公告。3. 学生查看公告列表，看到未读标识。4. 学生打开公告详情。5. 系统记录已读状态，列表同步更新。 |
| 备选/异常流程 | 学生不能发布公告；未选课学生不能访问课程公告；正文或标题不合法时不能发布；有权限的教师可编辑或删除。                           |
| 可验证结果   | 公告归属、内容和阅读状态正确；未授权用户不可发布或访问。                                                 |

### UC04 发布并获取课程资料

| 项目      | 说明                                                                 |
| ------- | ------------------------------------------------------------------ |
| 参与者     | 教师、学生。                                                             |
| 触发条件    | 教师上传/维护资料，或学生浏览、收藏、下载资料。                                           |
| 前置条件    | 教师是课程负责人；学生已选课；文件符合平台限制。                                           |
| 主成功流程   | 1. 教师上传资料并补充标题或说明。2. 系统保存资料记录和文件。3. 学生浏览或预览资料。4. 学生收藏资料。5. 学生下载资料。 |
| 备选/异常流程 | 学生不能上传；未选课学生不能访问；超限或非法文件被拒绝；不存在或已删除的资料不可下载。                        |
| 可验证结果   | 资料列表、收藏和下载结果正确；下载文件与已上传内容一致；访问控制有效。                                |

### UC05 完成作业发布、提交、批改和重做

| 项目      | 说明                                                                                                                |
| ------- | ----------------------------------------------------------------------------------------------------------------- |
| 参与者     | 教师、学生。                                                                                                            |
| 触发条件    | 教师发布作业；学生提交；教师批改、发布成绩或处理重做申请。                                                                                     |
| 前置条件    | 教师拥有课程；学生已选课且属于作业适用范围；作业已发布。                                                                                      |
| 主成功流程   | 1. 教师配置题目、截止时间和提交规则后发布。2. 学生查看要求，填写文本或上传附件。3. 学生提交，系统记录版本和迟交情况。4. 教师评分并填写反馈。5. 教师发布成绩。6. 学生查看成绩；允许重做时可申请，获批后再次提交。 |
| 备选/异常流程 | 未发布、未选课或不适用学生不可提交；不允许迟交时，截止后提交被拒绝；未批准重做不可再次提交；非教师不可批改或发布。                                                         |
| 可验证结果   | 作业在学生端、教师端和完成情况统计中的状态一致；提交版本、迟交、评分、发布和重做审批可追溯。                                                                    |

### UC06 完成实验发布、提交和自动评测

| 项目      | 说明                                                                                                                               |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 参与者     | 教师、学生、评测 Worker。                                                                                                                 |
| 触发条件    | 教师发布实验集/题目；学生提交代码或文件。                                                                                                            |
| 前置条件    | 学生已选课；实验在允许访问和提交时间窗内；自动评测时队列和 Worker 可用。                                                                                         |
| 主成功流程   | 1. 教师创建实验集并配置时间、语言和评测模式。2. 教师添加题目、公开/隐藏用例和附件。3. 学生查看题目并提交。4. 系统保存提交并将自动评测任务投入队列。5. Worker 执行用例并回写状态、得分和反馈。6. 学生查看本人结果，教师查看进度和统计。 |
| 备选/异常流程 | 窗口外不可提交；手动评测进入待人工处理；隐藏用例的输入输出不对学生公开；教师可按次数限制打回；Worker 不可用时提交停留待评测并应作为环境异常处理。                                                     |
| 可验证结果   | 提交状态从待评测到终态可查询；分数、反馈、最高成绩、打回/补交和教师统计一致；隐藏用例不泄露。                                                                                  |

### UC07 完成练习组卷、答题和错题反馈

| 项目      | 说明                                                                                             |
| ------- | ---------------------------------------------------------------------------------------------- |
| 参与者     | 学生；教师维护题库、标签与问题反馈。                                                                             |
| 触发条件    | 学生选择智能、知识点、错题或自定义模式开始练习。                                                                       |
| 前置条件    | 学生已选课；存在满足条件且答案已确认的练习题。                                                                        |
| 主成功流程   | 1. 学生选择练习模式和筛选条件。2. 系统生成练习会话。3. 学生逐题作答并保存。4. 学生提交会话。5. 系统评分、展示解析并写入错题。6. 学生可请求提示/辅导，必要时提交题目反馈。 |
| 备选/异常流程 | 没有匹配题目时提示；未提交的会话不提前暴露答案；教师不能以学生角色组卷；题目反馈仅教师或管理员可处理；大模型不可用时可使用本地提示或返回服务异常。                      |
| 可验证结果   | 会话、答案、得分、错题本、提示/辅导和反馈状态一致，且学生不能越权获取题库答案。                                                       |

### UC08 参与实验讨论并接收提醒

| 项目      | 说明                                                                                          |
| ------- | ------------------------------------------------------------------------------------------- |
| 参与者     | 学生、教师。                                                                                      |
| 触发条件    | 课程成员在课程、实验集或实验题讨论区发帖、评论、回复或提及成员。                                                            |
| 前置条件    | 用户具有相应课程或实验访问权限；附件符合限制。                                                                     |
| 主成功流程   | 1. 用户进入讨论区。2. 发布帖子，可添加附件或提及成员。3. 其他成员查看、评论或回复。4. 系统保存内容和层级关系。5. 系统向被提及用户创建通知。6. 教师可置顶或处理讨论。 |
| 备选/异常流程 | 无访问权限时拒绝；仅作者或教师/管理员可编辑/删除；置顶仅教师可执行；附件下载仍须校验访问关系。                                            |
| 可验证结果   | 帖子、评论、附件、提及通知和置顶/解决状态正确，权限边界有效。                                                             |

### UC09 配置并查看课程综合成绩

| 项目      | 说明                                                                                                    |
| ------- | ----------------------------------------------------------------------------------------------------- |
| 参与者     | 教师、学生。                                                                                                |
| 触发条件    | 教师配置权重或查看成绩册；学生查看个人成绩总览。                                                                              |
| 前置条件    | 教师拥有课程；课程存在选课记录及可统计的作业或实验成绩。                                                                          |
| 主成功流程   | 1. 教师查看当前作业和实验权重。2. 教师调整权重。3. 系统校验两项权重之和为 1。4. 系统按实验和已发布作业成绩计算总评。5. 教师查看或导出成绩册。6. 学生查看本人分项、总评和排名并可导出。 |
| 备选/异常流程 | 权重超范围或总和不为 1 时拒绝；非课程教师不能查看或修改；未发布的作业分数不展示给学生；无成绩项目时不伪造分数。                                             |
| 可验证结果   | 权重、总评公式、教师成绩册、学生成绩页和导出文件一致。                                                                           |

### UC10 管理选课阶段、用户和操作记录

| 项目      | 说明                                                                                       |
| ------- | ---------------------------------------------------------------------------------------- |
| 参与者     | 管理员。                                                                                     |
| 触发条件    | 管理员维护选课阶段，查看/删除用户，或查看审计、用户日志和作业完成情况。                                                     |
| 前置条件    | 管理员已登录。                                                                                  |
| 主成功流程   | 1. 管理员进入后台查看平台概览。2. 查询或更新选课阶段、开放和关闭时间。3. 查看用户列表与指定用户记录。4. 按规则删除用户。5. 查看管理员审计记录和课程作业完成矩阵。 |
| 备选/异常流程 | 非管理员访问被拒绝；用户不存在时返回不存在；不能删除当前登录管理员；系统至少保留一名管理员；非法阶段参数被拒绝。                                 |
| 可验证结果   | 选课阶段对 UC01 生效；用户、日志和完成矩阵可查询；删除保护与权限控制正确。                                                 |

## 5. 待确认事项

1. UC03/UC04、UC08 是否作为独立验收用例，仍待教师或助教确认；本说明沿用当前业务基线。
2. UC06 的 Python 评测依赖运行环境，需在验收环境明确 Python 运行器及回退策略。
3. UC07 智能组卷当前实现存在固定题量约束，需确认是否应作为正式需求。
4. UC10 包含平台支撑能力与完整管理流程，最终验收范围应明确其是否独立计入业务用例。
