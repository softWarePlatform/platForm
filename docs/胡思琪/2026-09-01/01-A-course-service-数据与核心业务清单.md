# A 任务清单：course-service 数据归属与核心业务

- 日期：2026-09-01
- 范围：课程域独立 Schema、迁移以及 UC01—UC04、UC10 的核心公开 API。

## 今日目标

让课程域表只由 `course-service` 读写，并使课程、选课、公告、资料和管理流程在独立服务中完成主要业务校验。外部服务只能通过课程服务接口查询权限、名单和课程信息。

## 任务清单

- [ ] 提取课程域 Prisma Schema 和版本化迁移；建立独立数据库或独立 schema 的连接配置，并确保迁移可从空库重复执行。
- [ ] 处理跨服务关联：作业、实验、讨论等外域记录在课程服务中只保留/传递 ID，不建立跨库联表或跨服务 Prisma 查询。
- [ ] 迁移用户、角色与课程权限校验；未登录、角色不符、非课程成员和课程不存在均返回统一错误格式。
- [ ] 完成 UC01：课程目录、选课、退课、候补、容量、时间冲突、选课阶段和课表同步。
- [ ] 完成 UC02：课程创建、编辑、发布、课表/容量配置与课程代码唯一性校验。
- [ ] 完成 UC03：公告创建、编辑、删除、排序、已读/标记与通知写入。
- [ ] 完成 UC04：资料上传、列表、下载、收藏、删除及文件类型/大小/成员权限校验；不得在响应中暴露物理存储路径。
- [ ] 完成 UC10 中归课程服务的选课阶段、用户管理和管理审计接口，并保护管理员权限。
- [ ] 为每个迁移后的路由补齐最小 API 冒烟测试，覆盖至少一个正常流程和一个越权或非法参数流程。

## 完成标准与证据

1. 空数据库可依次执行迁移和 seed，课程域数据可重复生成。
2. 课程域表不再由 homework 或 lab 服务直接写入；代码审查中无跨库连接或跨服务表查询。
3. UC01—UC04、UC10 的核心 API 在独立服务地址上可访问，主流程和权限异常均有自动化断言。
4. 输出数据库表归属、迁移命令、测试命令、已知未迁移路径与提交记录。
