# 成绩统计

## 成绩统计（学生端和老师端不同）

### 老师端

- 展示选课班级内的人员名单，每行列出一个学生
- 列表列包含：学号、姓名、每次作业得分、每次实验得分、期中/期末成绩、总评成绩
- 支持按任意成绩列排序（升序/降序）
- 支持按学生姓名/学号搜索定位
- 支持按班级筛选（若教师教授多个班级）
- 支持按分数段筛选（如只显示<60分的学生）
- 统计图包含：
  - 班级成绩分布直方图（分数段人数）
  - 每次作业/实验的平均分变化趋势折线图
  - 各分数段人数占比饼图
  - 最高分/最低分/平均分/标准差统计卡片
- 支持导出全班成绩为CSV/Excel，字段与页面展示一致
- 支持批量导入成绩（用于线下考试后录入）
- 支持设置成绩规则：各分项权重（如作业30%、实验30%、期末40%），修改后自动重算总评并提示“重算将覆盖原有总评”
- 支持成绩正态化调整（按需，提供调整前后对比预览）
- 支持生成个人成绩单PDF（学生可下载）

### 学生端

- 展示个人每次作业/实验的得分、班级平均分、最高分
- 排名信息：
  - 每次作业/实验的个人排名（如“第8名/共32人”）
  - 排名百分位（如“超过75%的同学”）
  - 总评成绩的班级排名和百分位
- 班级统计图：
  - 班级分数分布柱状图（高亮显示自己所在位置）
  - 个人成绩与班级平均分对比折线图（横轴为各次作业/实验）
  - 成绩雷达图（若按知识点维度展示，展示各知识点掌握程度对比班级平均）
- 显示总评成绩的计算公式和各项贡献得分（如“作业加权得分=85×0.3=25.5”）
- 支持查看历史学期的成绩归档
- 支持“生成成绩分析报告”：AI分析成绩趋势、波动情况、与班级对比的综合评价
- 支持导出个人成绩单（PDF/图片格式）
