# 界面说明

界面只保留标签、状态、错误与必要操作提示；详细规则与流程见本文档及各模块专项文档。

## 演示账号

见项目根目录 `RUN.txt`。常用账号：学生 `student@demo.local`、教师 `teacher@demo.local`，密码均为 `Demo123456`。

## 主界面

- **个人课表**：周视图，可切换周次；格子可点击进入课程。自定义事项与选课同步规则见 [主界面.md](./主界面.md)。
- **我的课程**：按分类折叠展示；无课程时显示「教学台」或「选课系统」入口链接。
- **搜索**：按课程名称过滤当前列表。

## 教学台

- **布局**：上方「新建课程」，下方「我的课程」列表。
- **新建课程**：填写名称、学期等必填项后保存；详细字段见课程管理流程。
- **实验 / 作业 / 练习**：从教学台子导航进入对应管理页；空列表仅显示「暂无…」标题，不附带操作引导段落。

## 课程页

进入某门课后，顶部 Tab 切换：公告、作业、实验、资料、练习、成绩（权限不同可见项不同）。

| 模块 | 界面保留 | 详细说明 |
|------|----------|----------|
| 公告 | 标题、正文、发布时间 | [课程公告.md](./课程公告.md) |
| 作业 | 标题、截止、状态、得分 | [作业管理.md](./作业管理.md) |
| 实验 | 实验集列表、题目状态 | [实验管理.md](./实验管理.md) |
| 资料 | 文件名、上传时间 | [课程资料管理.md](./课程资料管理.md) |
| 练习 | 组卷方式、答题记录 | [练习.md](./练习.md) |
| 成绩 | 表格或「暂无权限」 | [成绩统计.md](./成绩统计.md) |

## 作业

### 教师发布

- **基本信息**：标题、描述、截止时间。
- **附件**：支持常见文档与压缩包；单个文件大小与数量限制以表单校验为准。
- **迟交**：勾选后配置扣分规则；不勾选则截止后不可提交。
- **重做**：勾选后配置次数与是否需审批；学生批改后可「申请重做」。
- **评分标准**：可上传 rubric 文件；学生端显示文件名，可下载查看。

### 学生提交

- 截止前可编辑；**正式提交**后内容锁定，等待批改。
- **迟交**：若教师允许，超时仍可提交，历史版本会标注迟交天数。
- **申请重做**：批改发布且作业允许重做时出现；理由是否必填由作业设置决定。
- **删除作业**：在可编辑状态下可删除当前提交并重新填写。

## 实验

### 浏览层级（学生「我的实验」）

1. 课程列表 → 2. 实验集（每次作业）→ 3. 题目列表 → 4. 做题页。

**状态色含义**（左侧色条与标签一致）：

| 颜色 | 含义 |
|------|------|
| 灰 | 未开始 / 无提交 |
| 黄 | 进行中（部分完成或未全部 AC） |
| 绿 | 全部题目 AC |
| 红 | 仅题目行：未通过或需重做 |

列表按 **未完成 → 已完成** 排列（做完的自动靠后）；同组内较新的在前。**每页 5 条**，翻页在列表底部。

- **未开始**：白底 + 灰色标记块
- **进行中**：暖白底 + 细进度条 + 百分比
- **已全部通过**：极浅青绿渐变 + 右侧分数徽章（非整块浓绿）

### 提交与评测

- 选择**评测语言**后编写代码，点击「提交评测」（手动批改模式为「提交待批改」）。
- 评测进行中显示等待时长进度条；超过约 60 秒未完成，多为 Redis 或 `judge-worker` 未启动，见 `RUN.txt` 第 5 节。
- **公开样例**：展示输入、期望输出与实际输出（若有）。
- **隐藏用例**：仅显示「隐藏用例」与通过/未通过，不展示具体输入输出。
- **逐样例详情**：自动评测返回 `details`；无数据时显示「暂无逐样例评测详情」。

### 实验 AI 助手

- 可**关联某次提交**，后续对话自动带入该次代码与评测结果；点击「取消关联」可解除。
- 「最近回复」一行标明来源为大模型或本地模板。

### 教师出题

- 创建题目后显示**题目 ID**；公开用例可在创建流程写入，**隐藏用例**需在实验管理页继续维护。
- 创建完成页展示选课人数、提交人数等聚合统计（新题多为 0）。

## 个人中心

- 四宫格：账号信息、密码、头像、退出等；按钮底部对齐。
- 无额外「演示流程」说明段落。
