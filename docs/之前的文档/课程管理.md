## 1. 模块范围

课程管理包含（不含实验集/单题实验的判题细节，但含课程页入口）：

| 子功能 | 说明 |
|--------|------|
| 课程 CRUD | 创建、编辑、发布、详情查询 |
| 课程中心 | 已发布课程列表、分类筛选、关键词搜索 |
| 学生选课 | 选课、重复选课拦截 |
| 班级管理 | 建班、改名、删班、学生分班 |
| 学生名单 | 教师查看选课学生及所属班级 |
| 课程资料 | 上传、列表、下载、删除（本地 `uploads`） |
| 知识图谱 | 按课程/实验标题生成 JSON，可写回课程 |
| 课程讨论区 | 列表、发帖（需已选课或教师） |
| 教师工作台 | 「我的课程」、跳转课程管理页 |

## 3. 已实现功能 + 实现逻辑

### 3.1 课程列表与筛选

- **接口**：`GET /courses/categories`、`GET /courses?category=&search=`
- **逻辑**：仅返回 `published: true`；`search` 对 `title`、`description` 做不区分大小写包含匹配；分类来自已发布课程的去重 `category`。
- **前端**：`Courses.tsx` 拉取分类下拉 + 列表，学生可进入详情并选课。

### 3.2 教师创建 / 编辑课程

- **接口**：`POST /courses`、`PATCH /courses/:id`、`GET /courses/:id`
- **逻辑**：
  - 创建时 `teacherId` 为当前登录教师；默认 `published: false`。
  - 修改仅 **课程所属教师** 或 **ADMIN**；未发布课程对学生返回 404（防泄露）。
  - 可改字段：标题、简介、分类、发布状态、开课/结课时间、`knowledgeGraphJson`。
- **前端**：`CourseManage.tsx`、`Teaching.tsx`。

### 3.3 学生选课

- **接口**：`POST /courses/:id/enroll`（可选 body：`classId`）
- **逻辑**：
  - 仅 `STUDENT` / `ADMIN`；课程必须已发布。
  - 数据库 `Enrollment` 唯一约束 `(userId, courseId)`，重复选课返回 **409**。
- **前端**：课程详情页触发选课。

### 3.4 班级管理

- **接口**：
  - `POST /courses/:id/classes` 建班
  - `GET /courses/:id/classes` 班级及班内学生
  - `PATCH /courses/:courseId/classes/:classId` 改名
  - `DELETE /courses/:courseId/classes/:classId` 删班（班内学生 `classId` 置空）
  - `PATCH /courses/:courseId/enrollments/:enrollmentId` 调整学生班级
- **逻辑**：班级必须属于当前课程；分班时校验 `classId` 属于该 `courseId`。
- **前端**：`CourseManage.tsx` 班级与学生名单 UI。

### 3.5 课程资料

- **接口**：
  - `GET /courses/:courseId/materials`
  - `POST /courses/:courseId/materials`（multipart：`file` + 可选 `title`）
  - `GET .../materials/:materialId/download`
  - `DELETE .../materials/:materialId`
- **逻辑**：
  - 查看/下载：已发布课程且已选课，或教师/管理员。
  - 上传/删除：仅课程教师或 ADMIN。
  - 文件写入 `UPLOAD_ROOT`（默认 `backend/uploads`），库表存 `storedPath`。
- **前端**：课程详情 / 管理页资料区。

### 3.6 知识图谱

- **接口**：`POST /courses/:id/knowledge-graph/generate`（body：`{ save?: boolean }`）
- **逻辑**：
  - `buildKnowledgeGraphFromCourse`：根节点为课程名；每个实验标题挂一条「实验」边；简介按句号/分号切分最多 8 个「要点」节点。
  - `save: true` 时把 JSON 字符串写入 `Course.knowledgeGraphJson`。
  - 也可通过 `PATCH /courses/:id` 直接维护 JSON。
- **前端**：管理页生成/展示图谱概览。

### 3.7 课程讨论区

- **接口**：`GET/POST /courses/:courseId/discussions`
- **逻辑**：发帖/查看需 **已选课** 或 **本课教师/ADMIN**；按 `createdAt` 倒序。
- **前端**：`CourseDetail.tsx` 讨论列表与发帖表单。

### 3.8 教师「我的课程」

- **接口**：`GET /courses/mine`
- **逻辑**：教师只看 `teacherId = 自己`；管理员看全部；附带作业测评概览（`teachingHomeworkOverviewForTeacher`）。
- **前端**：`Teaching.tsx`。

## 5. 数据模型要点

```
Course 1 ── * Class
Course 1 ── * Enrollment ── * User
Course 1 ── * CourseMaterial
Course 1 ── * DiscussionPost
Enrollment.classId → Class（可空，删班时 SetNull）
```

- 选课唯一：`@@unique([userId, courseId])`
- 删课程：级联删除班级、选课、资料、讨论等（见 schema `onDelete`）

## 6. 问题与解决方案（已遇到）

> 下列部分为**全项目联调**问题，但会在启动 `npm run dev` 时刷屏，容易误判为「课程模块报错」。

### 6.1 Redis：`ECONNREFUSED 127.0.0.1:6379`

| 项目 | 内容 |
|------|------|
| **现象** | `[ioredis] Unhandled error event: connect ECONNREFUSED 127.0.0.1:6379`，API 仍能 listen 3000 |
| **原因** | 本机 **未启动 Redis**（或 `backend/.env` 中 `REDIS_URL` 与实不符）；评测队列与健康检查依赖 Redis |
| **与课程关系** | 纯浏览/选课/改课程 **不必须** Redis；从课程页进入实验并 **提交评测** 需要 Redis + Worker |
| **解决** | 1）Windows 安装并启动 **Memurai/Redis**（默认 6379）<br>2）确认 `REDIS_URL=redis://127.0.0.1:6379`<br>3）重启 `npm run dev`；评测用 `npm run dev:full`<br>4）Docker 方案需能拉 `redis` 镜像：`docker compose up -d redis` |
| **代码侧（可选）** | 使用 `backend/src/lib/redis.ts` 统一连接并 `on('error')`，避免 Unhandled error 刷屏（若仓库已回退该文件，需重新合并） |

### 6.2 Docker 拉取 Redis 镜像失败

| 项目 | 内容 |
|------|------|
| **现象** | `docker compose up -d redis` 报 `registry-1.docker.io` 超时 |
| **解决** | 不用 Docker，改 **本机 Memurai**；或配置镜像加速/代理后再拉镜像 |

### 6.3 `db:seed` 报错 `Unknown argument emailVerifiedAt`

| 项目 | 内容 |
|------|------|
| **现象** | `prisma.user.upsert` 提示 `emailVerifiedAt` 不是合法字段 |
| **原因** | `schema.prisma` 已增加字段，但 **未执行** `npx prisma generate`，Client 仍是旧版 |
| **解决** | `cd backend` → `npx prisma generate` → `npm run db:seed` |
| **与课程关系** | seed 会写入演示课程/班级/选课；seed 失败则课程演示数据缺失 |

### 6.4 未发布课程学生看不到

| 项目 | 内容 |
|------|------|
| **现象** | 学生访问课程详情 404 |
| **原因** | 设计如此：`published: false` 时仅教师/ADMIN 可见 |
| **解决** | 教师在 `CourseManage` 将课程设为 **已发布** |

### 6.5 选课返回 409

| 项目 | 内容 |
|------|------|
| **现象** | `已选过该课程` |
| **原因** | `Enrollment` 唯一约束 |
| **解决** | 无需重复选课；测试可换学生账号或删库重跑 seed |

### 6.6 资料下载 403 / 404

| 项目 | 内容 |
|------|------|
| **现象** | 无法下载资料 |
| **原因** | 未选课且非教师；或 `uploads` 下文件被删 |
| **解决** | 学生先选课；教师检查 `backend/uploads` 路径与 `storedPath` 是否一致 |
