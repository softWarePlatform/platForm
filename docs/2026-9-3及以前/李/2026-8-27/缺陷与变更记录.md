## 四、非阻断事项

1. 前端构建提示主 JavaScript chunk 约 1.18 MB，超过 Vite 默认 500 kB 警告线；不影响本次验收，后续可通过路由懒加载拆包。
2. 宿主机 6379 已被 Docker Desktop 后端代理占用，Compose Redis 容器无法重新绑定该端口；现有 Redis 可用且 API readiness 通过。后续若必须单独启动 Compose Redis，可先确认占用的容器，或在根 `.env` 中为本项目配置其他 `REDIS_PORT`，不要直接结束未知进程。
3. Ingress 需要 NGINX Ingress Controller；没有控制器时仍可通过 NodePort `http://localhost:30080` 验收。
4. `migrate-job.yaml` 现在使用专用 `migrate` 阶段镜像 `teaching-platform-migrate:dev`；28 号 CI/CD 会构建并推送同提交 SHA 的迁移镜像，在应用发布前等待 Job 成功。
