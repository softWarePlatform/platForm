# UC01—UC04 自动化测试检查记录

## 一、运行方法

前置条件：PostgreSQL、Redis 和 API 已启动，数据库已经执行 migration 和 seed。

在项目根目录执行：

```powershell
npm run test:course
```

可选环境变量：

```powershell
$env:API_BASE_URL = "http://127.0.0.1:3000"
$env:UC_REPORT_PATH = "..\test-results\uc01-04.json"
npm run test:course
```

测试结果默认写入 `test-results/uc01-04.json`。全部通过时退出码为 0；任一断言、清理操作或覆盖项失败时退出码为 1。

## 四、数据库副作用检查

测试不仅检查 HTTP 返回值，还直接检查下列表：

- `Course`：创建、配置、发布状态。
- `EnrollmentLog`：课程创建日志。
- `Enrollment`：选课、退课和候补递补。
- `EnrollmentWaitlist`：加入候补及递补后删除。
- `AnnouncementRead`：首次阅读、重复阅读和切换未读。
- `CourseMaterial`：资料元数据及下载次数。
- `MaterialFavorite`：收藏唯一性及取消收藏。

## 五、清理规则

- 启动前仅清理标题以 `[UC27-AUTO]` 开头的历史测试课程。
- 结束时清理本次课程及其级联业务数据。
- 资料数据库记录删除前先删除对应测试文件。
- 清理本次生成的公告、资料和选课通知。
- 保存原选课窗口，测试结束后按原值恢复。
- 不删除演示账号，不删除数据库卷，不修改非测试课程。
