## 4. C 已经交付（你们可以当现状用）

### 作业服务

- UC05：创建 / 发布 / 提交 / 批改 / 发布成绩 / 重做 / 附件 / GradingConfig  
- 权限：`GET /internal/courses/:id/access/:userId`，写操作 fail-closed（超时/5xx → 503）  
- 名单、通知走 A 内部接口；通知失败**不回滚**成绩发布  
- 实验成绩客户端：先 GET `.../lab-gradebook`，404 再 POST `.../lab-grades:batch`  
- 错题：`POST /homework/:id/wrong-book` 调 Lab PUT；读错题走网关 `/api/wrong-book/**` → Lab  
- 单体 `backend` 默认不再挂作业路由（对照时才设 `MONOLITH_HOMEWORK_ROUTES=1`）

### 网关

- 作业路径（含 `/api/courses/:id/homework|gradebook|grading-config`）→ `:3002`  
- 登录 / 选课 → `:3001`；实验 / 错题本 → `:3003`  
- `X-Request-ID`；限流；下游挂了 **502** `{ code, message, requestId }`

### 容器（交给 D，未上集群）

- `homework-grade-service/Dockerfile`、`api-gateway/Dockerfile`  
- `k8s/homework-grade-service/`、`k8s/api-gateway/`  
- 本地镜像标签 `:dev`（与 A 的 course 一致）；生产请 D 换成 `sha-<gitsha>`，不要 `latest`  
- 下游 URL 已写成集群 DNS，例如 `http://course-service:3001`

### 已跑通的证据

- 经网关 `:3081` UC05 冒烟  
- 经前端 Vite `localhost:5173/api` 同一条 UC05（Lab 未起）  
- Lab 未起：`GET /api/labs` → 502 `BAD_GATEWAY`；成绩册 200、`totalScore=null`、有 `provisionalTotal`
