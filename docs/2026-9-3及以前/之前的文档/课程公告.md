# 课程公告

## 课程公告模块详细设计

### 功能定义

- **教师权限**：发布公告、修改公告、删除公告、置顶公告
- **学生权限**：查看公告列表、查看公告详情
- **所有课程内成员**（含教师、学生、助教）均可看到公告

### 数据字段

- 公告ID
- 所属课程ID
- 标题
- 内容（富文本，支持图片/链接/代码块）
- 是否置顶（布尔值）
- 发布者ID（教师）
- 发布时间
- 最后修改时间
- 修改记录（可选，JSON格式存储修改历史）

### 教师端功能

#### 发布公告

- 入口：课程主页 → 公告栏区域 → “发布公告”按钮
- 表单：标题（必填，1-100字符）、内容（必填，富文本编辑器）
- 发布后：
  - 公告出现在课程公告列表顶部（按置顶+时间排序）
  - 发送站内通知给所有选课学生（标题：“【课程公告】XXX”）
  - 主界面通知中心增加一条未读

#### 修改公告

- 入口：每条公告右侧 → “编辑”按钮（仅自己发布的公告可编辑）
- 可修改：标题、内容、置顶状态
- 修改后：
  - 更新最后修改时间
  - 记录修改历史（可选，显示“已编辑”标识）
  - 不重复发送通知（除非教师手动勾选“重新通知”）

#### 删除公告

- 入口：每条公告右侧 → “删除”按钮（仅自己发布的公告可删除）
- 二次确认弹窗：“删除后不可恢复，确定删除吗？”
- 删除后：从公告列表移除，关联通知保留但跳转提示“公告已删除”

#### 置顶公告

- 入口：编辑公告时勾选“置顶” 或 列表页直接点击置顶图标
- 置顶规则：置顶公告始终显示在普通公告上方；多条置顶按发布时间倒序

### 学生端功能

#### 查看公告列表

- 入口：课程主页 → 公告栏区域
- 列表显示：标题、发布者、发布时间、是否置顶标识、是否为新公告（24小时内发布显示“NEW”标签）
- 分页：每页10-20条，按置顶+发布时间倒序排列
- 未读标识：学生看过某公告后标记为“已读”，未读公告在列表加粗显示

#### 查看公告详情

- 点击公告标题进入详情页
- 显示：完整内容、发布者、发布时间、最后修改时间（若有修改）
- 详情页自动标记该公告为“已读”

### 通知联动

- 新公告发布时：
  - 站内通知中心增加一条记录
  - 主界面顶部导航栏的🔔图标显示未读数量+1
  - 可选：邮件通知（如果平台集成了邮件）
- 学生点击通知后跳转到课程公告详情页
