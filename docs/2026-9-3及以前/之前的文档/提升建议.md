# 平台提升建议（视觉 / 交互 / 工程 / 高级感）

> 面向当前仓库 `platForm` 的可执行改进清单。  
> 原则：**先收敛门面、再统一系统、最后加功能**——高级感来自一致性与关键路径打磨，而非堆模块。

---

## 一、现状诊断（基于代码扫描）

| 维度 | 现状 | 影响 |
|------|------|------|
| 样式 | 单文件 `styles.css` 约 2900 行；`practice.css`、`enrollment.css` 等散落 | 改一处易牵动全局，新旧风格并存 |
| 内联样式 | 50+ 个 `.tsx` 含 `style={{}}`，`LabSetManage.tsx` 等重灾区 | 间距/颜色无法复用，视觉不一致 |
| 布局组件 | 已有 `PageShell`、`PageHeader`、`FormSection`、`EmptyState` 等 | 未全站强制使用，页面观感参差 |
| 加载态 | 多为纯文字「加载中…」，无骨架屏 | 显得粗糙、跳跃感强 |
| 反馈 | 部分仍用 `window.confirm` / `alert` | 打断感强，像内部工具 |
| 测试 | 后端仅 `lab-set-status.test.ts`；前端无测试 | 重构成本高，易回归 |
| 工具链 | 前端无 ESLint / Prettier / 组件文档 | 风格漂移、Review 困难 |
| 数据气质 | Seed 含「演示」「迁移生成」等命名 | 一眼像开发环境 |
| 文档 | `docs/` 产品愿景完整，部分与 UI 不同步 | 自己看也会觉得「没做完」 |

**结论**：业务能力中上，产品包装与工程规范中下。下面按优先级给出可落地项。

---

## 二、总策略：三条主路径 + 一个设计系统

### 2.1 对外只打磨三条「黄金路径」

演示 / 验收时只走这三条，其余模块入口可收拢或标「Beta」：

1. **学生**：登录 → 主界面课表 → 进入课程 → 实验列表 → 做题提交 → 看评测结果  
2. **学生**：登录 → 课程 → 作业列表 → 提交作业 → 查看成绩  
3. **教师**：登录 → 教学台 → 实验管理 / 作业批改（二选一深做）

**执行**：在 `Shell.tsx` 导航中，非核心项可改为课程内入口，顶部导航控制在 5–7 项。

### 2.2 设计系统最小集（必须先定死）

在 `styles.css` 的 `:root` 已有 token，需**写成规范并禁止绕过**：

| Token | 用途 | 禁止做法 |
|-------|------|----------|
| `--brand` / `--brand-soft` | 主操作、链接、焦点 | 页面内写 `#4f46e5` |
| `--text` / `--muted` | 正文 / 次要信息 | 混用 `#0f172a`、`#64748b` 等硬编码 |
| `--space-1` … `--space-6` | 外边距、gap | 随意 `marginTop: 12` |
| `--radius` / `--radius-lg` | 卡片、按钮 | 每页不同圆角 |
| `--shadow` / `--shadow-hover` | 卡片层级 | 多重 `box-shadow` 叠加 |

**新增建议 token**（写入 `:root` 后全站替换）：

```css
--surface-card: #ffffff;
--surface-muted: var(--surface-section);
--focus-ring: 0 0 0 3px rgba(79, 70, 229, 0.22);
--transition-fast: 0.15s ease;
--transition-base: 0.22s ease;
```

### 2.3 页面骨架标准（每个新页 / 改版页必须满足）

```
PageShell
  └─ PageHeader（title + lead + actions）
  └─ [可选] SubNav / Breadcrumb
  └─ 主内容区（单一大容器，最多再套一层 section）
  └─ ListPagination / EmptyState
```

**硬规则**：课程页、教学台、我的实验/作业 **最多两层可见容器**（`PageShell` 算外层，内层 `panel` 或 `lab-assign-stack` 算一层）。

按黄金路径逐页改版，每页完成后打勾。

#### 页面清单与具体动作

| 页面 | 文件 | 动作 |
|------|------|------|
| 登录/注册 | `Login.tsx`, `Register.tsx` | 居中卡片、品牌区、去掉多余说明；错误用 inline alert |
| 主界面 | `Home.tsx`, `WeeklySchedule.tsx`, `CourseListPanel.tsx` | 课表与课程列表同一栅格节奏；课程卡片复用 `entity-card` |

| 做题页 | `Lab.tsx`, `LabSubmitPanel.tsx` | 左题右码或上下分栏固定最小高度；评测结果用折叠面板统一样式 |
| 作业列表 | `CourseHomework.tsx`, `MyHomework.tsx` | 与实验列表同构：状态 pill + 右侧 meta，禁止表格裸奔 |

| 教学台 | `TeachingHub.tsx`, `Profile.tsx` | 保持 2×2 对称；图标可选（见 3.3） |

#### 内联样式清零计划

1. 用 `rg "style=\{\{" frontend/src` 按文件行数排序  
2. 每周清 3 个文件：把间距改为 class，颜色改为 token  
3. **冻结**：新增 PR 不允许在新文件写 `style={{`（ESLint 规则 `react/forbid-dom-props` 或自定义 script）

#### `styles.css` 拆分（降低维护成本）

```
frontend/src/styles/
  tokens.css      /* :root */
  base.css        /* body, a, typography */
  components/
    btn.css
    panel.css
    course.css
    lab-explorer.css
    homework.css
  index.css       /* @import 汇总 */
```

`main.tsx` 只引 `index.css`。**按模块迁移**，不要一次性大爆改。

### 3.3 P2 — 高级感细节（持续）

参考仪表盘类产品的共性（柔和渐变、大圆角、轻阴影、留白），在本项目落地为：

| 手法 | 落地位置 | 注意 |
|------|----------|------|
| 大圆角卡片 | 列表外容器 `lab-assign-stack` 已示范 | 全站卡片统一 `var(--radius-lg)`，勿混 8px/12px/16px |
| 轻渐变背景 | 已完成实验、统计卡片 | 白 → 极浅绿/靛白，**避免整块高饱和** |
| 数字强调 | 分数、进度 | 独立徽章容器（`lab-assign-bar__score-badge` 已示范） |
| 微动效 | 卡片 hover | 仅 `translateY(-2px)` + 阴影，尊重 `prefers-reduced-motion` |
| 图标 | 导航、空状态 | 一套 SVG（Heroicons / Lucide），24px 线宽 1.5 |

**不建议**：大面积动效、彩虹边框、过多插画——与「学术教学」气质不符。

#### 关键「爽感」时刻（Moment）

| 事件 | 当前 | 建议 |
|------|------|------|
| 实验全部 AC | 卡片变绿 | 可选：首次完成轻量 confetti 或勾选动画（仅一次，localStorage 记） |
| 作业提交成功 | 无 / 文字 | Toast + 按钮短暂「已提交」态 |
| 评测 AC | 结果区文字 | 结果标题绿色 + 「通过」徽章 0.3s fade-in |
| 选课成功 | alert? | Toast + 课程出现在主界面列表顶部 |

#### Demo 气质剥离

| 项 | 操作 |
|----|------|
| Seed 课程名 | `程序设计基础（演示）` → `程序设计基础`；副标题用学期区分 |
| 实验集名 | 去掉「迁移生成」；用「第 N 周实验」 |
| 登录页 | 演示账号提示移到 `docs/界面说明.md`，页脚小字链到文档即可 |
| 占位图 | 空课程/空资料用统一插画（一张 SVG 复用），勿纯文字 |

## 四、工程可维护性（可执行）

### 4.1 前端

#### 4.1.1 工具链（1 天内可完成）

在 `frontend/package.json` 增加：

```json
"scripts": {
  "lint": "eslint src --ext .ts,.tsx",
  "format": "prettier --write \"src/**/*.{ts,tsx,css}\"",
  "typecheck": "tsc --noEmit"
}
```

推荐规则：

- `@typescript-eslint/no-unused-vars`  
- 禁止默认导出与命名导出混用（可选）  
- `no-restricted-syntax`：限制 `style={{`（渐进：先 `warn`）

#### 4.1.2 数据请求层

当前 `api/client.ts` 仅注入 token。建议扩展：

```ts
// 响应拦截：401 → 清 token → /login
// 错误归一：{ message: string, code?: string }
export function getApiError(e: unknown): string { ... }
```

全站 `catch` 块改为 `getApiError(e)`，**删除**各处重复的 `response?.data?.error` 三元表达式（已在 20+ 文件重复）。

#### 4.3 自定义 Hooks 收敛

| 重复模式 | 建议 Hook |
|----------|-----------|
| `useState` + `useEffect` + `reload` | `useAsyncData(fetcher)` |
| 分页 | `usePagination(items, pageSize)` |
| 表单提交 busy/err | `useSubmit(fn)` |

实验模块已有 `useLabSetOverview`、`useLabSetMyProgress`，作业/公告可类推。

#### 4.1.4 类型与 API 契约

- 后端路由返回体在 `backend/src` 已有类型时，前端 `features/*/types.ts` 与之后端对齐  
- 可选：用 `openapi-typescript` 从 Fastify schema 生成客户端类型（中长期）  
- 禁止 `as any` 穿透组件 props  

#### 4.1.5 组件目录规范

```
components/
  layout/     # 页面级：PageShell, PageHeader, EmptyState
  ui/         # 原子：Button, Dialog, Toast, Skeleton
  homework/   # 领域
  labs/
features/     # 可复用业务块 + hooks + types
pages/        # 路由入口，尽量薄
```

**规则**：`pages/*.tsx` 超过 300 行必须拆到 `features/` 或 `components/`（`LabSetManage.tsx`、`CoursePractice.tsx` 优先拆）。

### 4.2 后端

#### 4.2.1 测试补齐（按风险排序）

| 优先级 | 模块 | 建议测试 |
|--------|------|----------|
| P0 | `lab-set-status.ts`, `lab-set-penalty.ts` | 状态机、截止时间边界 |
| P0 | `homework-student.ts` | 迟交扣分、重做次数 |
| P1 | `enrollment-service.ts` | 容量、候补 |
| P1 | `practice-grade.ts` | 评分逻辑 |
| P2 | 路由层 | 关键 API 集成测试（supertest） |

目标：**核心 lib 覆盖率 > 60%**，不必追求全路由 E2E。

#### 4.2.2 路由瘦身

部分 `routes/*.ts` 超过 500 行（如 `lab-sets.ts`）。模式：

```
routes/lab-sets.ts     → 仅注册路由 + 校验
lib/lab-set-*.ts       → 业务逻辑（已有部分）
```

#### 4.2.3 错误响应统一

全 API 错误格式：

```json
{ "error": "人类可读说明", "code": "LAB_SET_CLOSED" }
```

前端 `getApiError` 只读 `error` 字段；`code` 用于分支（如静默重试）。

## 六、页面级验收标准（Definition of Done）

任一页改版完成需满足：

1. 使用 `PageShell` + `PageHeader`（或课程壳等价结构）  
2. 无新增 `style={{`（迁移除外需备注）  
3. 加载、空、错三态齐全  
4. 主操作唯一且明显  
5. 移动端 375px 宽度无横向滚动（教学平台常投屏，但手机查看需可用）  
6. 键盘：主按钮可 Tab 聚焦，焦点环可见（`--focus-ring`）

## 七、推荐工具与参考（非必须引入）

| 用途 | 选项 | 说明 |
|------|------|------|
| 图标 | [Lucide](https://lucide.dev) | 与现有线型风格接近 |
| Toast | sonner / react-hot-toast | 轻量 |
| 对话框 | 自研 80 行 + portal | 避免重型 UI 库 |
| 图表 | 成绩页可用 recharts | 仅 1–2 页需要 |
| CSS | 保持 CSS 变量 + 模块化文件 | 暂不强制 Tailwind，减少迁移面 |

美学参考方向：**柔和留白 + 单一主色（靛蓝）+ 少量青绿成功态**，避免多色仪表盘照搬。
