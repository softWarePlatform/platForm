# 在线教学平台用户手册

## 1. 平台简介

本平台面向学生、教师和管理员三类用户，支持课程管理、选课、公告、资料、实验、作业、成绩、练习、消息通知等教学流程。

不同身份登录后会进入对应的功能入口：

- 学生：查看课程、完成作业与实验、查看成绩、接收消息。
- 教师：管理课程、发布公告和资料、布置与批改作业、管理实验、查看学生完成情况。
- 管理员：管理用户、班级、课程运行情况、操作日志和作业完成情况。

## 2. 登录与个人中心

1. 打开平台首页。
2. 点击“登录”。
3. 输入账号邮箱和密码。
4. 登录成功后，系统会根据账号身份展示对应导航。
5. 可在“个人中心”查看或修改个人信息。

如果尚无账号，可通过“注册账号”创建新账号，或联系管理员创建账号。

## 3. 学生端使用说明

### 3.1 查看我的课程

学生登录后可在首页或课程入口查看已加入课程。

点击课程卡片可进入课程详情页。课程内通常包含：

- 公告
- 作业
- 实验
- 成绩
- 练习
- 资料

### 3.2 选课

1. 进入“选课”页面。
2. 浏览可选课程。
3. 选择课程和班级。
4. 点击选课按钮。
5. 选课成功后，课程会出现在学生课程列表中。

如课程容量已满或选课阶段关闭，系统会提示原因。

### 3.3 查看公告

1. 进入课程。
2. 点击“公告”。
3. 点击公告标题查看详情。
4. 阅读公告后，未读状态会自动更新。

### 3.4 查看课程资料

1. 进入课程。
2. 点击“资料”。
3. 可查看、预览或下载教师上传的课程资料。
4. 支持收藏常用资料。

### 3.5 完成作业

学生可从以下入口进入作业：

- 课程内“作业”页面
- “我的作业”页面
- 首页待办或截止提醒
- 消息通知中的作业提醒

作业详情页中可查看：

- 作业要求
- 截止时间
- 面向班级
- 附件
- 当前提交状态
- 教师反馈与成绩

提交作业流程：

1. 进入作业详情页。
2. 阅读作业要求。
3. 根据作业要求填写文本答案或上传附件。
4. 点击“正式提交”。
5. 提交成功后，作业状态会更新。

如果教师允许重做，且成绩已发布，学生可在作业详情页申请重做。

### 3.6 查看已完成作业

1. 进入“我的作业”。
2. 在已提交/已完成作业列表中点击作业卡片。
3. 系统会进入该作业详情页。
4. 可查看提交内容、提交历史、成绩和教师反馈。

### 3.7 完成实验

1. 进入课程。
2. 点击“实验”。
3. 选择实验集或实验题目。
4. 按要求完成代码或实验内容。
5. 提交后查看评测结果和完成状态。

### 3.8 查看成绩

1. 进入课程。
2. 点击“成绩”。
3. 查看实验成绩、作业成绩、总评成绩和排名信息。

也可在“我的作业”中查看课程总评概览。

### 3.9 使用练习功能

1. 进入课程。
2. 点击“练习”。
3. 选择练习模式或知识点。
4. 完成题目后查看结果。
5. 如支持 AI 辅导，可在练习中查看提示或答疑。

### 3.10 查看消息

1. 点击顶部导航中的“消息”。
2. 查看站内通知。
3. 点击消息后，系统会根据消息类型跳转：
   - 作业消息跳转到作业详情
   - 公告消息跳转到公告详情
   - 资料消息跳转到课程资料
   - 实验消息跳转到实验页面
   - 练习消息跳转到课程练习

点击“全部已读”可将所有消息标记为已读。

## 4. 教师端使用说明

### 4.1 查看教学工作台

教师登录后可进入“教学”页面，查看自己负责的课程、作业和实验。

### 4.2 管理课程

1. 进入教师课程。
2. 点击课程管理入口。
3. 可维护课程信息、班级、学生、知识图谱和课程资料。

### 4.3 发布公告

1. 进入课程。
2. 点击“公告”。
3. 填写公告标题和内容。
4. 发布后，学生会收到公告消息。

### 4.4 上传课程资料

1. 进入课程。
2. 点击“资料”。
3. 上传资料文件。
4. 可对资料进行编辑、删除或版本管理。

### 4.5 布置作业

1. 进入课程。
2. 点击“作业管理”。
3. 在“发布中心”填写作业信息：
   - 标题
   - 要求
   - 截止时间
   - 面向班级
   - 附件
   - 评分标准
   - 是否允许迟交或重做
4. 点击发布。

发布后，学生可在课程作业页和“我的作业”中看到该作业。

### 4.6 批改作业

教师可从以下入口进入批改：

- 教学端作业列表
- 课程内作业详情
- 作业相关消息通知

批改流程：

1. 打开作业详情。
2. 查看学生提交内容和附件。
3. 输入分数和反馈。
4. 点击保存。
5. 批改完成后，可统一发布成绩。

如启用 AI 建议，可先生成 AI 批改建议，再决定是否应用。

### 4.7 处理重做申请

当学生申请重做后，教师端作业批改页会显示“重做申请”区域。

教师可执行：

- 通过申请
- 拒绝申请并填写原因

处理后，学生会收到对应消息反馈。

### 4.8 发布作业成绩

1. 进入作业详情。
2. 完成批改。
3. 点击“发布成绩”。
4. 学生端可查看分数和反馈。

### 4.9 管理实验

1. 进入课程。
2. 点击“实验”。
3. 创建或维护实验集。
4. 添加实验题目、测试用例和要求。
5. 查看学生实验完成情况。

### 4.10 查看消息

教师消息会根据类型跳转到对应页面，例如：

- 学生提交作业 → 作业批改页
- 学生申请重做 → 作业批改页
- 课程公告或讨论消息 → 对应课程页面

## 5. 管理员端使用说明

### 5.1 管理员控制台

管理员登录后进入管理员后台，可查看平台整体运行情况。

### 5.2 用户管理

1. 进入“用户管理”。
2. 查看学生、教师、管理员账号。
3. 可新增、编辑或删除用户。
4. 可查看指定用户日志。

### 5.3 班级目录

1. 进入“班级目录”。
2. 查看课程班级信息。
3. 维护课程与班级关系。

### 5.4 管理员操作日志

1. 进入“管理员操作日志”。
2. 查看管理员关键操作记录。
3. 可用于审计用户删除、管理操作等行为。

### 5.5 查看作业完成情况

1. 进入管理员后台。
2. 点击“作业完成情况”。
3. 选择课程。
4. 查看该课程下学生作业完成矩阵。

页面会展示：

- 学生数量
- 作业数量
- 总体完成率
- 每个学生每项作业的状态
- 成绩是否已发布
- 是否存在重做申请

### 5.6 查看课程作业日志

在“作业完成情况”页面选择课程后，可查看课程作业日志，包括：

- 学生提交作业
- 教师批改作业
- 教师发布成绩
- 学生申请重做

日志用于帮助管理员追踪课程作业流转情况。

### 5.7 管理员消息

管理员也可进入“消息”页面查看系统通知。

消息会根据类型跳转至对应管理员可访问页面。

## 6. 消息跳转规则

平台消息支持按类型跳转：

| 消息类型 | 跳转页面 |
| --- | --- |
| 作业消息 | 对应课程作业详情 |
| 公告消息 | 对应课程公告详情 |
| 资料消息 | 对应课程资料页 |
| 实验消息 | 对应课程实验页 |
| 练习消息 | 对应课程练习页 |
| 选课消息 | 课程管理或选课相关页面 |
| 管理消息 | 管理员日志或相关管理页面 |

系统会根据当前登录身份自动选择学生端、教师端或管理员端路由。

## 7. 常见问题

### 7.1 看不到课程

可能原因：

- 学生尚未选课。
- 教师不是该课程负责人。
- 管理员账号未进入正确后台入口。
- 登录状态已过期。

建议重新登录，或联系管理员确认课程权限。

### 7.2 作业无法提交

可能原因：

- 作业未发布。
- 已超过截止时间且不允许迟交。
- 作业已正式提交并锁定。
- 附件格式不符合要求。
- 当前账号未加入该课程。

### 7.3 已完成作业在哪里查看

进入“我的作业”，在已提交/已完成作业列表中点击作业卡片，即可进入详情。

### 7.4 学生申请重做后教师看不到

教师应进入对应作业的批改页，查看“重做申请”区域。

如果仍未显示，可刷新页面或检查该学生是否确实提交了重做申请。

### 7.5 消息点击后没有跳转

可能原因：

- 对应资源已删除。
- 当前账号无权限访问目标页面。
- 历史消息缺少完整资源信息。

可从课程页面手动进入对应模块查看。

## 8. 使用建议

学生建议：

- 经常查看“消息”和“我的作业”。
- 提交作业前确认附件已上传成功。
- 成绩发布后及时查看反馈。

教师建议：

- 发布作业前确认面向班级和截止时间。
- 批改后及时发布成绩。
- 定期查看重做申请。

管理员建议：

- 定期查看用户日志和管理员操作日志。
- 使用“作业完成情况”追踪课程作业执行情况。
- 发现异常时结合消息、日志和课程详情排查。
