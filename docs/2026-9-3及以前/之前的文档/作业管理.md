# 作业管理：

## 作业管理

### 老师端

#### 发布/修改作业内容（可上传资料）

- 发布作业时填写：作业标题（必填，1-100字符）、作业描述（富文本，支持图片/公式/代码块/表格）
- 支持上传附件资料，格式限制：.pdf/.doc/.docx/.zip/.rar，单个文件≤20MB，最多10个附件
- 支持设置发布对象：全班 或 指定班级（多平行班场景）
- 支持设置是否允许迟交，若允许则配置迟交扣分规则（如“每日扣减10%最高分”“超过3天按0分计”）
- 支持设置是否允许重做，若允许则配置最多重做次数（1/3/5/无限次）
- 支持设置提交类型：个人作业 或 小组作业（小组作业需设置小组规模上限）
- 支持上传评分标准文件或设置分项评分维度（如代码质量40分、文档30分、运行结果30分）
- 发布后作业状态默认为“未发布”（对学生不可见），教师点击“发布”后学生可见
- 已发布的作业可撤回，撤回后学生端不可见但已提交数据保留
- 修改作业时，可修改的内容包括：作业描述、附件（增删）、截止时间、迟交规则、重做规则
- 修改截止时间若提前，需二次确认并提示“可能影响学生已规划时间”
- 所有修改记录历史，并在学生端显示“作业要求已更新”提示

#### 批改

- 待批改列表按班级筛选，支持按提交状态（已提交/未提交/已批改/已打回）筛选
- 列表排序支持：按提交时间、按学生姓名、按学号、按得分
- 每个提交项显示：学生姓名、学号、提交时间、提交附件列表、当前得分（若已批改）、打回次数
- 提交附件支持在线预览（PDF/图片/纯文本）和下载
- 批改界面包含：
  - 总分输入（数值，支持小数点后一位）
  - 分项打分（若发布时设置过分项维度）
  - 评语输入（富文本，支持预设评语模板库）
  - 是否打回重做（勾选后需填写打回原因）
- 打回重做时记录打回次数，学生端显示打回原因和剩余重做次数
- 支持标记优秀作业，标记后可匿名展示给全班（需学生同意）
- 批改后可选“保存草稿”（学生不可见）或“发布成绩”（学生对可见）
- 支持批量导出所有提交附件（按学生文件夹整理）
- 支持CSV批量导入分数和评语（用于离线批改后上传）
- 支持作业逾期自动标记，并按迟交规则自动扣减分数（教师可手动覆盖）

#### 是否允许迟交

- 作业发布时可独立配置“是否允许迟交”
- 若不允许迟交，截止时间后提交入口关闭，无法提交
- 若允许迟交，需配置迟交规则：
  - 迟交扣分方式（按固定分扣减 或 按百分比扣减）
  - 扣减粒度（按天/按小时）
  - 最大扣减上限（如最多扣至60分）
  - 迟交最晚期限（如截止后7天为最终期限）
- 允许迟交的作业，学生提交时系统提示“本次提交已超时X天，将扣减Y分”
- 教师可在批改时手动覆盖系统自动扣减的分数

### 学生端

#### 提交

- 作业列表显示每个作业：标题、截止时间、状态（未开始/进行中/已提交/已逾期/已打回）、得分（若已批改）
- 状态“已打回”时显示打回原因和剩余重做次数
- 提交界面包含：
  - 作业要求展示区（阅读后需勾选“我已阅读作业要求”）
  - 提交内容输入（富文本 或 文件上传，取决于作业设置）
  - 已提交历史列表（若作业允许多次提交，显示历次提交时间和版本）
- 支持草稿保存，下次进入自动加载
- 提交前做必填校验（如附件必传时检查）
- 提交成功后显示“提交成功”并发送站内信通知
- 截止时间前可多次覆盖提交（若作业设置允许多次提交）
- 截止时间后若允许迟交，仍可提交但系统提示扣分规则
- 提交后等待批改期间，提交内容锁定不可修改

#### 申请重做

- 作业批改发布后，若得分不满意且作业设置了“允许重做”，学生端显示“申请重做”按钮
- 点击后填写重做申请理由（可选，可配置是否必填）
- 申请提交后状态变为“重做申请待审批”
- 教师审批通过后，作业状态重置为“进行中”，学生可重新提交
- 重做次数用完后，“申请重做”按钮置灰并显示“已达最大重做次数”
- 重做提交后的作业独立存档，保留历次提交记录和得分
- 教师批重视作作业时，可选择覆盖原成绩或保留最高分（教师端配置）

#### 知识漏洞（AI调用）

- 基于作业批改结果（错题、扣分点、评语中的知识点标签），AI自动分析学生知识薄弱点
- 在作业详情页底部展示“知识漏洞分析”，包含：
  - 本次作业涉及的知识点列表
  - 每个知识点的掌握程度评估（薄弱/一般/良好）
  - 薄弱知识点对应的错题或扣分项
- 点击薄弱知识点，AI自动生成：
  - 知识点讲解（文字/图文）
  - 相关例题推荐（来自题库）
  - 针对性练习建议（如“建议完成XX实验/章节练习”）
- 支持学生主动提问：“这道题为什么错了？”——AI解析错误原因并给出正确思路
- 支持“生成错题本”，将薄弱知识点相关题目自动加入个人错题本
- 错题本可导出为PDF，支持标记“已掌握”后移除
- 支持“推荐学习路径”：AI综合多个作业的漏洞，推荐优先复习的知识点顺序
