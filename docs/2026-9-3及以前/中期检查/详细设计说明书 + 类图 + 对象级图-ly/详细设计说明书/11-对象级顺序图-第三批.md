## 2. OBJ-UC03 公告发布、通知与阅读

### 2.1 对象映射

| 对象实例 | 类/模块 | 类型 | 职责 |
| --- | --- | --- | --- |
| `teacher`、`student` | `User` | Actor/Entity | 发布公告或阅读公告的课程成员 |
| `announcementPage` | `CourseAnnouncements` | Boundary | 展示公告列表并提交发布表单 |
| `detailPage` | `CourseAnnouncementDetail` | Boundary | 打开详情并展示正文、已读和标记状态 |
| `shell` | `Shell` | Boundary | 通过 SSE/未读计数刷新消息角标 |
| `api` | `AxiosInstance` | Gateway | 附加 JWT 并发送公告、通知请求 |
| `announcementController` | `AnnouncementsRoutes` | Control | 课程访问校验、参数校验和公告 CRUD |
| `accessService` | `CourseAccessService` | Service | 判断教师管理权或学生选课关系 |
| `announcementService` | `AnnouncementService` | Service | 批量通知学生、序列化公告和统计未读 |
| `notificationBus` | `NotificationEvents` | Service | 向在线用户发送 SSE 刷新事件 |
| `prisma` | `PrismaClient` | Repository | 读写公告、选课、已读和通知记录 |
| `announcement` | `CourseAnnouncement` | Entity | 保存公告标题、正文、置顶和编辑历史 |

| `notification` | `SiteNotification` | Entity | 保存公告通知及其已读时间 |

```mermaid
  participant detail as detailPage:CourseAnnouncementDetail

  alt 未选课或无权查看
    controller-->>api: HTTP 403 未选课或无权查看
  else 有课程访问权
    par 查询公告
      controller->>announcement: courseAnnouncement.findMany(courseId)
    and 查询已读记录
      controller->>read: announcementRead.findMany(studentId,announcementIds)
    and 查询重要标记
      controller->>prisma: announcementMark.findMany(studentId,announcementIds)
    end
    controller-->>api: {announcements:[read,marked,...]}
    api-->>page: render list

  alt 公告已删除

  else 公告存在

      Note over controller,notification: 打开详情同步两类已读状态
      controller->>read: announcementRead.upsert(announcementId,studentId,readAt)
      read->>prisma: INSERT or UPDATE AnnouncementRead
      controller->>notification: siteNotification.updateMany(userId,announcementId,readAt=null)
      notification->>prisma: UPDATE matching notifications readAt
    end
    controller-->>api: HTTP 200 {announcement,read:true,editHistory}
    api-->>detail: render announcement
    detail-->>student: 展示正文并标记已读
  end
```

### 2.2 关键方法逻辑

1. 发布接口通过 `getCourseAccess()` 判断 `isTeacher`，不能仅依赖前端隐藏按钮。
2. 公告创建成功后，`notifyStudentsOfAnnouncement()` 查询课程全部选课学生，批量创建 `ANNOUNCEMENT` 通知并发送 SSE 刷新事件。
3. 打开公告详情调用 `markAnnouncementRead()`，以 `(announcementId,userId)` 唯一键 upsert `AnnouncementRead`。
4. 同一次阅读还会更新对应 `SiteNotification.readAt`，保证公告列表状态与消息中心状态一致。
5. 公告被删除时详情接口返回 HTTP 404 和 `deleted=true`，前端展示明确的已删除状态。

## 3. OBJ-UC04 资料上传、可见性、收藏与下载

### 3.1 对象映射

| 对象实例 | 类/模块 | 类型 | 职责 |
| --- | --- | --- | --- |
| `teacher`、`student` | `User` | Actor/Entity | 上传管理资料或查看、收藏、下载资料 |
| `materialsPage` | `CourseMaterials` | Boundary | 承载课程资料页面 |
| `materialsPanel` | `MaterialsPanel` | Boundary | 上传文件、筛选、收藏和下载操作 |
| `api` | `AxiosInstance` | Gateway | 发送 multipart 和普通 HTTP 请求 |
| `materialController` | `CourseMaterialsRoutes` | Control | 权限、multipart、版本、下载响应控制 |
| `policy` | `CourseMaterialPolicy` | Service | `canViewMaterials()`、`materialVisibleToUser()` 等授权策略 |
| `uploadService` | `UploadsService` | Service | 校验大小、安全命名并保存文件 |
| `notificationService` | `CourseMaterialService` | Service | 创建资料通知并推送 SSE 事件 |
| `prisma` | `PrismaClient` | Repository | 读写资料元数据、收藏和下载计数 |
| `fileStore` | `UploadFileStore` | External Resource | 保存和流式读取物理文件 |
| `material` | `CourseMaterial` | Entity | 保存文件元数据、可见性、版本和统计 |
| `favorite` | `MaterialFavorite` | Entity | 保存用户与资料的收藏关系 |

```mermaid
sequenceDiagram
  autonumber
  actor teacher as teacher:User
  actor student as student:User
  participant page as materialsPage:CourseMaterials
  participant panel as materialsPanel:MaterialsPanel
  participant api as api:AxiosInstance
  participant controller as materialController:CourseMaterialsRoutes
  participant policy as policy:CourseMaterialPolicy
  participant upload as uploadService:UploadsService
  participant notify as notificationService:CourseMaterialService
  participant prisma as prisma:PrismaClient
  participant material as material:CourseMaterial
  participant favorite as favorite:MaterialFavorite
  participant files as fileStore:UploadFileStore

  teacher->>panel: upload(files,title,folder,visibility,targetClassId,notify)
  panel->>api: postMultipart(/courses/{courseId}/materials, FormData)
  api->>controller: POST materials + Bearer token
  controller->>prisma: course.findUnique(courseId)
  controller->>policy: canManageMaterials(userId,role,course)

  alt 非任课教师/管理员
    policy-->>controller: false
    controller-->>api: HTTP 403 无权上传
    api-->>panel: 显示权限错误
  else 有管理权
    controller->>controller: parse multipart parts
    controller->>controller: validate files, visibility, targetClassId
    alt 无文件、可见范围非法、班级不存在或文件过大
      controller-->>api: HTTP 400 {error}
      api-->>panel: 显示校验错误
    else 校验通过
      loop 每个上传文件

          controller->>material: courseMaterial.findMany(groupId,lastVersion)

        end

        upload->>files: write sanitized file
        files-->>upload: {storedPath,fileName}
        upload-->>controller: stored file metadata

        material->>prisma: INSERT CourseMaterial

          controller->>notify: notifyStudentsOfMaterial(courseId,materialId,title)
          notify->>prisma: siteNotification.createMany(type=MATERIAL)
        end
      end
      controller-->>api: HTTP 200 {materials}
      api-->>panel: refreshMaterials()
      panel-->>teacher: 显示上传成功
    end
  end

  student->>page: openMaterials(courseId,filters)
  page->>api: get(/courses/{courseId}/materials?q&folder&fileType&favorites)
  api->>controller: GET materials
  controller->>policy: canViewMaterials(studentId,role,course)

  alt 未选课或无权查看课程资料
    controller-->>api: HTTP 403
  else 可查看课程资料
    controller->>prisma: enrollment.findUnique(studentId,courseId)
    prisma-->>controller: enrollmentClassId
    controller->>material: courseMaterial.findMany(courseId,isCurrent=true)
    material->>prisma: SELECT current materials
    controller->>policy: materialVisibleToUser(each,{isManager:false,enrollmentClassId})
    Note right of policy: ALL 全员；CLASS 仅目标班；TEACHER_ONLY 对学生隐藏
    controller->>favorite: materialFavorite.findMany(studentId,visibleMaterialIds)
    controller->>controller: apply folder/search/type/date/favorite filters
    controller-->>api: HTTP 200 {materials,folders,isManager:false}
    api-->>page: render visible materials

  opt 学生收藏资料

    panel->>api: post(/courses/{courseId}/materials/{materialId}/favorite)

    controller->>material: findFirst(id,courseId,isCurrent=true)
    controller->>favorite: materialFavorite.upsert(userId_materialId)
    favorite->>prisma: INSERT if absent
    controller-->>api: HTTP 200 {ok:true}
  end

  student->>panel: download(materialId)
  panel->>api: get(/courses/{courseId}/materials/{materialId}/download)
  api->>controller: GET download
  controller->>policy: canViewMaterials() + materialVisibleToUser()
  alt 资料不存在、文件丢失或不可见
    controller-->>api: HTTP 404/403 {error}
  else 允许下载
    controller->>files: access(absStoredPath)
    files-->>controller: file exists
    controller->>material: update(downloadCount+1,lastDownloadAt=now)
    controller->>files: createReadStream(absPath)
    files-->>controller: file stream
    controller-->>api: stream + Content-Disposition attachment
    api-->>panel: 保存原文件名文件
    panel-->>student: 下载完成
  end
```

### 3.2 关键方法逻辑

1. 上传使用 multipart；控制器逐个读取文件到 Buffer，并按文件类型调用 `maxBytesForFile()` 限制大小。
2. `saveCourseMaterialFile()` 负责安全文件名和物理存储，`CourseMaterial` 保存 `storedPath`、MIME、大小、可见性和版本信息。
3. 替换资料时复用 `groupId`、版本号加一，并把旧版本置为 `isCurrent=false`。
4. 列表查询先进行课程访问检查，再使用 `materialVisibleToUser()` 执行 `ALL/CLASS/TEACHER_ONLY` 细粒度过滤。
5. 收藏使用 `(userId,materialId)` 唯一键 upsert，重复收藏保持幂等。
6. 下载前重新执行可见性和物理文件存在性检查；成功后增加 `downloadCount`、更新 `lastDownloadAt` 并流式返回文件。

### 4.2 关键方法逻辑与边界

1. `canDiscussLab()` 校验实验存在以及当前用户是否为管理员、任课教师或已选课学生。
2. `MentionComposer` 从 `/courses/:courseId/discussion-members` 获取候选人并解析 `@`；后端 Zod 仅验证 ID 为 UUID。
3. `notifyMentions()` 使用 `Set` 去重并排除作者本人，随后批量创建 `DISCUSSION` 通知。
4. 通知写入后调用 `emitNotificationToUsers()`；在线接收人的 `Shell` 收到 SSE 事件后刷新未读数。
5. 帖子详情查询同时加载评论和附件，并把 `viewCount` 加一；返回结果按作者、教师和管理员计算编辑、删除、置顶权限。
6. 通知已读接口先以 `(notificationId,currentUserId)` 查询，防止用户修改他人的通知。
7. 当前后端没有再次校验 `mentionUserIds` 是否属于该课程，主要依赖前端成员列表；若需要更强安全约束，应在 `notifyMentions()` 前增加课程成员过滤。
