## 1. 填写说明

| 列 | 填写规则 |
| --- | --- |
| 需求 ID | 使用 `UCxx-Rnn`。`UCxx` 对应基线业务用例，`Rnn` 为该用例内两位流水号。 |
| 需求描述/验收准则 | 可由测试直接判定；避免只写“实现页面”“优化体验”等不可验收表述。 |
| 设计项 | 页面、组件、接口、数据模型、状态机或交互规则，可多项并列。 |
| 代码实现 | 仓库相对路径，必要时补充函数/路由/组件名称；不绑定易变化的行号。 |
| 测试与证据 | 测试编号、脚本或证据文件。`已验证`必须能定位可复现证据；`待补`不能写通过。 |
| 状态 | `已验证`、`待补测试`、`待确认`、`阻塞`、`不适用` 五选一。 |
