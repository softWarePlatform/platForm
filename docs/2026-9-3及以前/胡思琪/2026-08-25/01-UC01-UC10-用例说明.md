## 1. 适用角色与通用约束

| 角色 | 说明 |
| --- | --- |
| 学生 | 选课后进入课程，完成学习、作业、实验和练习，并查看本人结果。 |
| 教师 | 创建和维护本人课程，发布教学内容，处理作业、实验与成绩。 |
| 管理员 | 维护选课阶段、用户、班级和平台运行记录；可按权限协助查看教学数据。 |
| 评测 Worker | 异步处理自动评测任务并回写实验提交状态与得分，不直接操作前端。 |

通用前置条件：用户已登录；需要课程访问的操作须具备教师归属、管理员身份或有效选课关系。服务端使用 JWT 鉴权，未登录返回 401，角色或课程访问不符合要求返回 403。

## 3. 用例详细说明

### UC01 完成选课、退课或候补并同步课表

| 项目 | 内容 |
| --- | --- |
| 参与者 | 学生（管理员维护选课窗口） |
| 触发 | 学生在选课目录对目标课程执行选课、退课或加入候补。 |
| 前置条件 | 已登录；选课阶段开放；目标课程存在且学生具备访问目录权限。 |
| 后置条件 | 选课成功则建立 `Enrollment` 并同步至个人课程/课表；退课则移除选课关系；候补成功则建立候补记录。 |
| 主成功场景 | 1. 学生查看选课目录和窗口状态。2. 选择未满课程。3. 系统校验阶段、重复关系和容量。4. 建立选课记录。5. 学生在首页课表和课程列表看到课程。 |
| 备选/异常 | 课程已满：返回冲突，学生可加入候补；重复选课或重复候补：返回冲突；未选课程退课：返回不存在；选课窗口关闭：拒绝操作。 |
| 验收要点 | 目录、选课关系、候补状态和 `/dashboard/me` 课程/时段一致；异常状态具有明确反馈。 |

### UC02 创建、配置并发布课程

| 项目 | 内容 |
| --- | --- |
| 参与者 | 教师 |
| 触发 | 教师在教学端创建课程并完成基础配置、课表和发布。 |
| 前置条件 | 教师已登录；课程代码未被占用。 |
| 后置条件 | 课程保存；发布后出现在公开课程目录；创建操作可审计。 |
| 主成功场景 | 1. 教师填写课程名称、代码、容量、学分等。2. 系统校验输入和唯一课程代码。3. 创建课程并记录创建日志。4. 教师补充课表/容量等配置。5. 发布课程。6. 学生能在公开目录检索到课程。 |
| 备选/异常 | 重复课程代码拒绝；学生创建课程拒绝；课程标题等必填信息缺失拒绝；非课程教师修改或发布拒绝。 |
| 验收要点 | 创建、日志、配置字段和发布可见性一致；课程代码唯一；权限与输入校验有效。 |

### UC03 发布并阅读课程公告

| 项目 | 内容 |
| --- | --- |
| 参与者 | 教师、学生 |
| 触发 | 教师发布课程公告，学生进入公告列表或详情阅读。 |
| 前置条件 | 教师为课程负责人；学生已选该课程。 |
| 后置条件 | 公告归属于课程；学生阅读详情后形成已读记录；可产生课程通知。 |
| 主成功场景 | 1. 教师填写标题和正文发布。2. 系统保存公告并向课程成员提供可见记录。3. 学生查看公告列表，显示未读。4. 学生打开详情。5. 系统写入已读状态，列表更新为已读。 |
| 备选/异常 | 学生发布、未选课学生查看均拒绝；标题或正文不符合校验拒绝；教师可在权限范围内编辑或删除。 |
| 验收要点 | 公告内容、课程归属、阅读状态和访问控制正确；前端以文本安全渲染用户输入。 |

### UC04 发布并获取课程资料

| 项目 | 内容 |
| --- | --- |
| 参与者 | 教师、学生 |
| 触发 | 教师上传或维护课程资料，学生浏览、收藏或下载。 |
| 前置条件 | 教师为课程负责人；学生已选该课程；上传文件符合大小与类型限制。 |
| 后置条件 | 资料元信息与文件存储可关联查询；收藏与下载行为对学生可用。 |
| 主成功场景 | 1. 教师上传资料并填写标题/说明。2. 系统保存文件与资料记录。3. 学生进入课程资料页浏览或预览。4. 学生收藏资料。5. 学生下载文件，内容与已上传版本一致。 |
| 备选/异常 | 学生上传、未选课访问拒绝；不存在或已删除资料返回不存在；超出文件限制或非法输入拒绝。 |
| 验收要点 | 列表、详情、收藏、下载与文件内容一致；删除资料时其文件按实现规则同步处理。 |

### UC05 完成作业发布、提交、批改和重做

| 项目 | 内容 |
| --- | --- |
| 参与者 | 教师、学生 |
| 触发 | 教师发布作业；学生保存/提交；教师批改、发布成绩或处理重做。 |
| 前置条件 | 教师拥有课程；学生已选课且属于适用班级；作业处于可见、可提交时间范围。 |
| 后置条件 | 保存提交版本、迟交标识、分数与评语；成绩发布后学生可查看；获批重做后可再次提交。 |
| 主成功场景 | 1. 教师配置题目、截止时间、提交规则并发布。2. 学生查看作业要求，填写文本或上传附件并提交。3. 系统记录版本和是否迟交。4. 教师查看提交，评分并给出反馈。5. 教师发布成绩。6. 学生查看成绩；如允许，申请重做并在审批后再次提交。 |
| 备选/异常 | 未发布、未选课或不适用班级不可提交；超过截止时间且不允许迟交时拒绝；重做未获批不可再次提交；非教师不可批改或发布成绩。 |
| 验收要点 | 作业状态在学生端、教师端、完成矩阵中一致；迟交、版本、评分、发布与重做审批可追溯。 |

### UC06 完成实验发布、提交和自动评测

| 项目 | 内容 |
| --- | --- |
| 参与者 | 教师、学生、评测 Worker |
| 触发 | 教师发布实验集/题目和测试用例；学生提交代码或文件。 |
| 前置条件 | 实验集已发布且在允许访问/提交时间窗内；学生已选课；自动评测模式下 Redis 与 Worker 可用。 |
| 后置条件 | 提交保存并经历 `PENDING/JUDGING` 到终态；得分、评测反馈和教师打回信息可查询。 |
| 主成功场景 | 1. 教师创建实验集，配置时间窗、语言和评测模式。2. 教师新增题目、公开/隐藏用例和附件。3. 学生查看题目并提交代码或文件。4. 自动模式将任务入 `judge-submissions` 队列。5. Worker 执行测试并回写 `ACCEPTED`、`WRONG_ANSWER`、`ERROR` 或 `TIMEOUT` 等结果。6. 学生查看本人反馈；教师查看进度和统计。 |
| 备选/异常 | 时间窗外不可提交；手动评测进入 `PENDING_REVIEW`；隐藏用例输入输出不向学生返回；教师可打回，次数达到上限后拒绝继续打回；Worker 未启动时任务可能停留在待评测，须作为环境检查项。 |
| 验收要点 | 实验集配置、提交记录、状态机、最高成绩、隐藏用例隔离、打回/补交和教师统计一致。 |

### UC07 完成练习组卷、答题和错题反馈

| 项目 | 内容 |
| --- | --- |
| 参与者 | 学生（教师维护题库、标签与反馈） |
| 触发 | 学生按智能、知识点、错题或自定义方式创建练习会话。 |
| 前置条件 | 学生已选课；课程存在可练习题目；题目标准答案已确认。 |
| 后置条件 | 保存练习会话、逐题答案与判题结果；错题进入错题本；学生可获得提示/辅导，教师可查看统计和题目反馈。 |
| 主成功场景 | 1. 学生选择练习模式和知识点筛选。2. 系统生成题目会话。3. 学生逐题作答并保存。4. 学生提交会话。5. 系统评分、展示结果和解析，并写入错题。6. 学生对难题请求提示或辅导；必要时提交题目反馈。 |
| 备选/异常 | 无符合筛选条件的题目时提示；教师不能以学生身份组卷；未完成/未提交会话不提前暴露标准答案；题目反馈仅由教师/管理员处理；未配置大模型时使用本地降级提示，调用失败可返回服务不可用。 |
| 验收要点 | 会话题目、作答、得分、错题本、统计与反馈状态一致；学生不能越权获取题库答案。 |

### UC08 参与实验讨论并接收提醒

| 项目 | 内容 |
| --- | --- |
| 参与者 | 学生、教师 |
| 触发 | 课程成员围绕课程、实验集或实验题发帖、评论、回复并提及成员。 |
| 前置条件 | 用户对课程/实验具备访问权限；上传附件符合限制。 |
| 后置条件 | 帖子、评论、附件和置顶/解决状态可查询；被提及用户获得站内通知。 |
| 主成功场景 | 1. 用户进入课程、实验集或实验题讨论区。2. 发布帖子，可指定被提及成员并添加附件。3. 其他成员查看详情并评论/回复。4. 系统保存讨论层级和附件。5. 系统为被提及用户创建通知。6. 教师可置顶、处理或删除权限范围内内容。 |
| 备选/异常 | 无课程访问权限拒绝；仅作者或教师/管理员可编辑/删除；置顶仅教师；附件下载需通过访问校验。 |
| 验收要点 | 讨论范围、作者、评论层级、提及通知、附件下载与权限规则一致。 |

### UC09 配置并查看课程综合成绩

| 项目 | 内容 |
| --- | --- |
| 参与者 | 教师、学生 |
| 触发 | 教师设置作业/实验权重或查看成绩册；学生查看个人成绩总览。 |
| 前置条件 | 教师拥有课程；课程已有选课关系及可统计的作业或实验成绩。 |
| 后置条件 | 保存合法权重；教师可查看/导出班级成绩册；学生可查看本人汇总、明细与排名。 |
| 主成功场景 | 1. 教师查看当前权重。2. 设置实验和作业权重，系统校验总和为 1。3. 系统依据实验最高分/实验集均分及已发布作业成绩计算总评。4. 教师查看成绩册或导出 CSV。5. 学生查看个人课程总评、分项和排名；学生导出个人成绩。 |
| 备选/异常 | 权重超范围或总和不为 1 拒绝；非课程教师查看或修改拒绝；作业未发布成绩不向学生展示具体分数；无成绩项目时保留空值而不伪造得分。 |
| 验收要点 | 配置、总评公式、教师成绩册和学生成绩页一致；导出内容与页面数据一致。 |

### UC10 管理选课阶段、用户和操作记录

| 项目 | 内容 |
| --- | --- |
| 参与者 | 管理员 |
| 触发 | 管理员维护选课阶段、查看/删除用户，或查看平台与用户操作记录。 |
| 前置条件 | 管理员已登录。 |
| 后置条件 | 选课阶段在全局生效；用户操作受保护；管理员相关操作留下可查看记录。 |
| 主成功场景 | 1. 管理员查看后台概览。2. 查看并更新选课阶段、开放和关闭时间。3. 查看用户列表及指定用户日志。4. 按规则删除目标用户。5. 查看管理员审计记录和课程作业完成情况。 |
| 备选/异常 | 非管理员访问管理接口拒绝；删除不存在用户返回不存在；不得删除当前登录管理员；系统至少保留一名管理员；选课阶段参数不合法拒绝。 |
| 验收要点 | 窗口状态对 UC01 生效；用户与审计记录可检索；删除保护规则和权限控制有效；完成矩阵数据可与作业状态对应。 |

## 4. 待评审与待补测项

1. UC03/UC04、UC08 是否维持独立验收，仍需教师或助教确认；本初稿按现有 D1 基线保留独立编号。
2. UC06 的 Python 评测依赖运行环境；Windows 未发现 `python3` 时应明确标为环境风险并补测回退方案。
3. UC07 智能组卷当前服务端固定抽取 10 题，请在需求评审中确认是否保留此约束或改为尊重 `count` 参数。
4. UC10 目前同时包含运行支撑与可验收管理流程，建议在最终验收范围中明确是否独立计入业务用例。
