## 使用约定

1. UC 编号是需求基线，未经评审不得重排或复用；新增业务用例从 `UC11` 起顺序编号。
2. 追溯表的一行对应一个可验收需求点，而不是一个页面或单个接口；同一需求允许关联多个设计、代码位置和测试项。
3. 代码位置均使用仓库相对路径；测试栏优先写可重复执行的测试编号、脚本或证据文件。
4. 本轮已有实测证据：UC01—UC04（2026-08-25 验证记录），其余 UC 的映射来自当前代码、历史测试报告和测试脚本，需在下轮按追溯表补齐证据。
