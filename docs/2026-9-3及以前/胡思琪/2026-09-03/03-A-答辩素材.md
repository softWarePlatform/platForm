# A：课程服务答辩素材

## 一分钟讲解

课程服务从单体拆出后，独占用户、课程、选课、公告、资料、通知和选课审计数据。作业与实验不复制到课程库；Dashboard 通过内部 HTTP 批量摘要接口聚合外域数据。任何上游不可用时，课程本地数据照常返回，并显式标记 `UNAVAILABLE`，不会把“未知”误报成零。

## 架构图

```text
学生/教师/管理员 → Gateway → course-service → course_service
                                  ├→ homework 摘要 API
                                  └→ lab 摘要 API
```

## 数据归属图

```text
course-service：Course / Enrollment / Announcement / Material / Notification
homework-grade-service：Homework / Submission / Grade
lab-practice-service：Lab / Practice / Judge / WrongBook
```

## 代表用例：UC01 选课

学生对开放课程执行选课。服务在同一事务内检查选课窗口、重复选课、容量与时间冲突，并创建选课审计记录。若课程时段冲突，返回 409，不创建选课记录。该正常/异常路径由 `npm run test:api` 自动验证。
