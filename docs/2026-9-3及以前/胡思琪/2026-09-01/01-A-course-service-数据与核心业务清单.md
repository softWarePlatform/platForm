# A 任务清单：course-service 数据归属与核心业务

- 日期：2026-09-01
- 范围：课程域独立 Schema、迁移以及 UC01—UC04、UC10 的核心公开 API。

## 今日目标

让课程域表只由 `course-service` 读写，并使课程、选课、公告、资料和管理流程在独立服务中完成主要业务校验。外部服务只能通过课程服务接口查询权限、名单和课程信息。

## 任务清单

- [x] 提取课程域 Prisma Schema 和版本化迁移；创建独立 `course_service` 数据库并验证迁移可重复部署。
- [x] 处理跨服务关联：作业、实验、讨论等外域表未进入课程服务 Schema；通知仅保留外部业务 ID，不建立跨库联表。
- [x] 迁移用户、角色与课程权限校验；未登录、角色不符、非课程成员和课程不存在均由 API 拒绝。
- [x] 完成 UC01 的最小完整链路：课程目录、选课、退课、候补、容量、时间冲突、选课阶段。
- [x] 完成 UC02：课程创建、编辑、发布、课表/容量配置与课程代码唯一性校验。
- [x] 完成 UC03 的最小完整链路：公告创建、课程成员读取、已读记录与通知写入。
- [x] 完成 UC04 的最小完整链路：资料上传、列表、下载、收藏、文件大小与成员权限校验；响应不暴露物理路径。
- [x] 完成 UC10 中归课程服务的选课阶段、用户管理和选课/建课审计接口，并保护管理员权限。
- [x] 新增可重复 API 冒烟测试，覆盖健康检查、教师建课/发布、学生越权拒绝、选课、时间冲突、公告已读、资料上传收藏下载和管理员审计。

## 完成标准与证据

1. 空数据库可依次执行迁移和 seed，课程域数据可重复生成。
2. 课程域表不再由 homework 或 lab 服务直接写入；代码审查中无跨库连接或跨服务表查询。
3. UC01—UC04、UC10 的核心 API 在独立服务地址上可访问，主流程和权限异常均有自动化断言。
4. 输出数据库表归属、迁移命令、测试命令、已知未迁移路径与提交记录。

验收证据见 `02-A-course-service-独立数据与迁移记录.md` 与 `03-A-course-service-API验收记录.md`；跨成员同步见 `04-A-course-service-同步说明.md`。
