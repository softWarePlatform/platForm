## 实验管理

### 学生端

- 在课程主页内展示“实验”模块，列出该课程所有实验
- 每个实验卡片显示：
  - 实验标题
  - 截止时间
  - 完成状态（未开始/进行中/已提交/已打回/已完成）
  - 得分（若已批改）
- 点击实验卡片进入实验详情页，包含：
  - 实验说明（教师编写，富文本）
  - 起始代码（若有）
  - 附件资料（指导书、数据文件等，可下载）
  - 提交入口（代码编辑器/文件上传）
- 代码编辑器支持：语法高亮、代码补全、多语言（C/C++/Java/Python）
- 提交后自动进入评测队列，显示“评测中”状态
- 评测完成后显示：得分、通过/未通过用例详情（隐藏隐藏用例的具体输入输出）

### 老师端

- 发布实验：
  - 填写实验标题、说明（富文本）、起始代码
  - 上传附件资料（指导书、测试数据等）
  - 设置截止时间
  - 设置允许的语言列表（如C++、Java、Python）
  - 设置是否允许多次提交/打回重做
  - 设置评测规则（测试用例、时间/内存限制）
- 修改实验：
  - 可修改截止时间（延长或提前，提前需二次确认）
  - 可修改实验说明和附件
  - 可增删/修改测试用例（隐藏用例修改后需重新评测已提交学生的代码，可配置是否自动重评）
- 查看学生提交列表：
  - 显示每个学生的提交次数、最新提交时间、得分
  - 支持按学生筛选、按得分排序
  - 点击学生可查看其历次提交的代码、评测结果、得分详情
- 打回重做：
  - 教师可打回不合格提交，填写打回原因
  - 打回后学生端状态变为“已打回”，学生可重新提交
  - 打回次数计入限制（教师可设置最大打回次数）

### 评测功能

- 评测系统接收提交后异步执行
- 运行环境资源限制：CPU时间≤2秒、内存≤256MB、输出长度≤1MB（可配置）
- 评测结果分类：
  - 通过（Accepted）
  - 答案错误（Wrong Answer）
  - 运行超时（Time Limit Exceeded）
  - 内存超限（Memory Limit Exceeded）
  - 运行时错误（Runtime Error，含段错误、除零等）
  - 编译错误（Compile Error，显示具体错误信息）
- 显示未通过样例的说明：
  - 公开用例：显示“样例X未通过”，并给出期望输出 vs 实际输出（截断显示）
  - 隐藏用例：仅显示“隐藏用例X未通过”，不透露具体输入输出
- 评分规则：
  - 每个测试用例设有分值，通过则得全分，不通过得0分（不支持部分分）
  - 编译错误/运行时错误得0分
  - 总分=通过用例分值之和
- AI优化建议：
  - 评测失败后，学生可点击“AI分析”
  - AI根据代码和错误信息给出：
    - 错误原因推测（如“数组越界，第15行访问了arr[10]但数组长度为10”）
    - 代码问题定位（指出可疑代码行）
    - 修改建议（如“将循环条件改为 i < n 而不是 i <= n”）
  - 对于超时问题，AI分析时间复杂度并给出优化方向（如“使用哈希表替代线性查找”）
  - 对于答案错误，AI对比期望输出与学生输出，提示逻辑差异

### 讨论区

- 实验详情页内嵌讨论区（也可独立于课程大讨论区）
- 学生可：
  - 发帖提问（标题、内容、可选是否匿名）
  - 回复他人帖子
  - 给自己的帖子标记“已解决”
- 教师可：
  - 回复帖子（教师回复有特殊标识）
  - 置顶常见问题帖
  - 删除不当内容
- 支持@功能：@教师可确保教师收到通知
- 支持代码块插入（语法高亮显示）
- 支持附件上传（截图、日志文件等）
- 帖子搜索：按标题/内容/作者搜索
- 热门问题自动推荐：系统根据浏览量和回复数在顶部展示“热门问题”

### 通知同步

- 实验截止前24小时，主界面待办卡片显示提醒
- 截止前1小时，发送站内信/浏览器通知
- 实验批改完成后，学生收到成绩通知
- 实验被教师打回时，学生立即收到通知（含打回原因）
- 教师发布新实验时，学生收到通知
