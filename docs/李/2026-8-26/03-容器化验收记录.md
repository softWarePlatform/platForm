## 4. 验收结论

当前结论：**Docker 构建与运行、浏览器主要页面、通知 SSE、课程资料、实际评测和自动集成测试均已通过。**

构建期间发生过 Docker Hub EOF、npm `ECONNRESET` 和 Debian 源 502；用户恢复代理连接后，借助缓存、重试和顺序构建完成。Worker 首次启动因 Prisma 生成了错误的 OpenSSL 1.1 引擎而退出；构建阶段安装 OpenSSL 后重新生成 3.0 引擎，复验通过。
