E2E 首轮在提交练习时出现 `spawn UNKNOWN`。修复内容：

1. JavaScript 运行器改用 `process.execPath`，不再依赖 PATH 中的 `node`；
2. Python 在 Windows 使用 `python`，Linux 使用 `python3`；
3. 补充 stdout/stderr 采集和 spawn 异常降级；
4. 新增 `UNIT-07-06`，验证代码题在 Windows/Linux 上能够执行并采集输出。

修复后 `E2E-07-01` 通过，最终 E2E 为 10/10。
