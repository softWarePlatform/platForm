## 2. 需求说明

### REQ01 / UC01 完成选课、退课或候补并同步课表

**参与者：** 学生；管理员维护选课阶段，教师查看课程名单。 
**触发与前置：** 学生已登录，在开放阶段对已发布课程执行选课、退课或候补。
**主流程：** 查看目录、容量、时段和本人状态 → 校验阶段、重复、容量与时间冲突 → 创建选课记录并占用名额 → 同步课程列表、教师名单和个人课表。 
**备选/异常：** 满课时可候补并按空位递补；退课释放名额且可触发递补；窗口关闭、课程未发布、重复选课或冲突时拒绝。 
**可验证结果：** 选课、候补、容量、成员名单和 `/dashboard/me` 课表一致；异常路径不创建正式选课记录。



### REQ02 / UC02 创建、配置并发布课程

**参与者：** 教师；管理员、学生为次要参与者。 
**触发与前置：** 教师已登录并具课程管理权限，需要新建或发布课程。 
**主流程：** 填写课程信息 → 配置容量、课表和地点 → 校验必填项与课程代码唯一性 → 创建草稿 → 确认并发布 → 进入学生课程目录。 
**备选/异常：** 代码重复或字段非法时拒绝；无权用户不可修改或发布；未发布课程不向普通学生开放；删除关联课程需受控处理。 
**可验证结果：** 教师可查询完整配置；发布课程学生可见；课程代码不可重复。

### REQ03 / UC03 发布并阅读课程公告

**参与者：** 教师、学生；通知服务为次要参与者。 
**触发与前置：** 课程教师发布公告，学生已选课。 
**主流程：** 填写并发布公告 → 保存并按置顶/发布时间排序 → 为成员生成通知和未读记录 → 学生打开详情 → 更新已读状态与未读数。 
**备选/异常：** 教师可编辑或删除；非成员不可读取，非课程教师不可发布；通知失败不能丢失公告主体。 
**可验证结果：** 公告内容、排序、通知、阅读记录和未读数一致。

### REQ04 / UC04 发布并获取课程资料

**参与者：** 教师、学生；文件存储模块为次要参与者。 
**触发与前置：** 教师上传资料，或具有课程权限的学生浏览、收藏、下载资料。 
**主流程：** 上传文件并填写说明 → 校验并保存元数据/文件 → 浏览资料列表 → 下载正确内容 → 收藏资料。 
**备选/异常：** 文件超限、参数不完整或存储失败时不保留无效元数据；无权访问、资料删除或文件缺失时返回明确错误。 
**可验证结果：** 资料列表、收藏和下载内容正确，且没有无效残留数据。

### REQ05 / UC05 完成作业发布、提交、批改和重做

**参与者：** 教师、学生；通知服务与 AI/本地降级模块为次要参与者。 
**触发与前置：** 作业规则、截止时间、迟交和重做规则已配置。 
**主流程：** 教师发布 → 学生保存草稿并正式提交 → 记录版本、时间和迟交状态 → 教师评分和评语 → 发布成绩 → 学生查看或按规则申请重做。 
**备选/异常：** 迟交按规则标识或拒绝；教师可打回；正式提交后限制修改；非法分数、越权和超出重做次数时拒绝。 
**可验证结果：** 学生端、教师端和完成统计状态一致；版本、评分、发布、迟交、打回和重做历史可追溯。

### REQ06 / UC06 完成实验发布、提交和自动评测

**参与者：** 教师、学生、评测 Worker；Redis 队列、通知与 AI/本地降级模块为次要参与者。 
**触发与前置：** 实验题、测试用例和时间窗已配置，学生提交代码或文件。 
**主流程：** 配置实验集和题目 → 学生提交 → API 创建 `PENDING` 记录并投递任务 → Worker 评测并写回终态、得分和反馈 → 学生查看脱敏结果，教师查看统计。 
**备选/异常：** 窗口外或规则不符时拒绝；手动评测进入 `PENDING_REVIEW`；错误、超时和答案错误分类展示；Worker 不可用时保持待评测。 
**可验证结果：** 提交经历“等待评测—评测中—终态”；得分与用例权重一致；隐藏用例不向学生泄露。

### REQ07 / UC07 完成练习组卷、答题和错题反馈

**参与者：** 学生；教师、AI/本地降级模块为次要参与者。 
**触发与前置：** 学生有课程权限，题库存在可用题目。 
**主流程：** 选择练习模式和筛选条件 → 创建练习会话 → 逐题作答并保存 → 提交会话 → 判分并显示解析 → 更新错题范围 → 请求提示、相似题或提交反馈。 
**备选/异常：** 题目不足时提示或缩减题量，不能创建空会话；AI 不可用时使用本地模板；题库管理和反馈处理仅教师/管理员可执行。 
**可验证结果：** 题目、答案、逐题结果、总分和错题范围一致；提示不改写正式答案或成绩。

### REQ08 / UC08 参与实验讨论并接收提醒

**参与者：** 学生、教师；通知服务为次要参与者。 
**触发与前置：** 课程成员在课程、实验集或实验题讨论区发布、回复或提及成员。 
**主流程：** 发布帖子和附件 → 成员评论/回复 → 提及时生成通知 → 被提及者打开讨论并更新已读 → 作者或教师标记已解决。 
**备选/异常：** 作者管理自己的内容，教师可处理不当内容；非成员不可读写；无效附件或提及对象被拒绝；通知失败不影响正文保存。 
**可验证结果：** 帖子、回复、附件、提及、通知、已读和已解决状态按课程/实验范围一致。

### REQ09 / UC09 配置并查看课程综合成绩

**参与者：** 教师、学生；作业和实验模块为次要参与者。 
**触发与前置：** 课程、选课关系及可计分结果存在，教师配置或查看成绩，学生查看个人成绩。 
**主流程：** 设置作业/实验权重 → 校验范围和总和 → 聚合已发布作业成绩、实验最高分和实验集均分 → 计算总评、排名和分布 → 教师查看/导出，学生查看本人结果。  
**备选/异常：** 非法权重保留原配置；未批改或未发布成绩显示为空或不计入；学生仅查看本人，教师仅管理有权课程。 
**可验证结果：** 教师成绩册、学生成绩和导出数据公式一致；权重非法或越权查询被拒绝。

### REQ10 / UC10 管理选课阶段、用户和操作记录

**参与者：** 管理员；学生、教师为次要参与者。 
**触发与前置：** 管理员已登录并通过管理员权限校验。 
**主流程：** 查看平台概况 → 配置选课阶段与开放/关闭时间 → 保存并使学生端状态生效 → 查询用户和操作记录 → 按约束管理用户 → 留下审计记录。 
**备选/异常：** 非管理员访问被拒绝；无效阶段或时间范围不可保存；关联教学数据的用户需拒绝或受控清理；故障不得泄露其他用户信息。 
**可验证结果：** `/enrollment/status` 与实际允许操作一致；管理员可查授权范围用户与审计；非管理员得到拒绝或重定向。

## 3. 验收与变更规则

每项需求至少关联一条主流程测试和一条异常或权限测试，并可追溯到设计、代码和证据。REQ 编号与 UC 编号一一对应且不得复用；需求语义变更须保留版本记录，并使用同一 REQ 编号执行回归。
