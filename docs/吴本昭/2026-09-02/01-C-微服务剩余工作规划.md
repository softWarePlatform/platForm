### W0-1 切 A 的 access（P0，第一件事）

改 `homework-grade-service/src/lib/course-client.ts` 的 `resolveCourseAccess`。

| 现在 | 改成 |
| --- | --- |
| Bearer `GET /courses/:id` + `GET /enrollment/catalog` | `GET /internal/courses/:courseId/access/:userId` |
| 课程详情也走公开 GET | 改 `GET /internal/courses/:courseId`（A 已冻结） |
| 名单已内部 | 保持 `GET /internal/.../enrollments`，继续兼容 `items` |
| 登录 | **仍走** A 公开 `GET /auth/me`（身份，不是权限） |

A 冻结响应（注意包在 `access` 里，不要当顶层字段）：

```json
{
  "access": {
    "userId": "…",
    "courseId": "…",
    "role": "STUDENT",
    "canView": true,
    "isTeacher": false,
    "isEnrolled": true,
    "classId": null,
    "classIds": []
  }
}
```

验收：

- 超时 **1s**；非 2xx / 超时 / 404 → **写操作拒绝**（创建、提交、批改、发布、改权重）。读列表可 403/404，禁止「失败当未选课却放行」。
- 不把调用方 `role` 传给 A（A：服务端自己查，不接受传入 role）。
- 按班发布作业：需要班级时再调 `GET /internal/courses/:courseId/classes`；没有 `targetClassId` 的路径可以后补，不要堵 access 切换。
- 单测：access 超时 / 401 / 404 → 写操作失败；教师 `isTeacher=true` 放行。
- 冒烟：创建作业、提交、批改不再依赖 catalog 做权限。

通知：A **只认** `Idempotency-Key` 头（缺则 400）。C 已带头+body，保持头即可；body 里的 `idempotencyKey` 可留着不影响。

令牌：与 A 当场对 `INTERNAL_SERVICE_TOKEN`。代码默认 `course-service-internal-local-token`；若 `.env` 是 `replace-with-service-token`，三服务必须同一串。对不上会出现名单 `UNAVAILABLE`、通知静默跳过、access fail-closed（写全挂）。

### W0-2 统一错误体（P1，可与 W0-1 同批）

作业服务对外/对内错误统一为：

```json
{ "code": "STRING", "message": "人类可读", "requestId": "uuid" }
```

现状：`internal.ts` 已是这套；`homework.ts` / `homework-student.ts` / `grades.ts` / `auth.ts` 大量 `{ error }`。

建议最小集合（不要一次重构所有文案）：

| HTTP | code |
| --- | --- |
| 400 | `INVALID_ID` / `INVALID_BODY` / `LATE_SUBMISSION` |
| 401 | `UNAUTHORIZED` |
| 403 | `FORBIDDEN` |
| 404 | `NOT_FOUND` / `HOMEWORK_NOT_FOUND` |
| 409 | `VERSION_CONFLICT` |
| 501 | `WRONG_BOOK_NOT_READY`（错题未切真之前） |
| 503 | `HOMEWORK_UNAVAILABLE` / `COURSE_UNAVAILABLE` |

网关 502 已是 `{ code: "BAD_GATEWAY", message, requestId }`，不要改形状。

### W0-3 修 `final-gradebook` 卡住并复跑冒烟（P0）

卡住点：`internalRequired` 是同步 preHandler。Fastify 5 会传入 `done` 第三参；成功路径既不 `async` 也不调 `done()`，handler 永不执行，表现成 `final-gradebook` 一直不返回。已改成 `async`。顺带：下游 `httpJson` 走直连 Agent + 墙钟超时，避免本机 `HTTP_PROXY` 把回环请求拐进 Clash。

验收：`npm run test:api` 通过；`GET /internal/courses/:id/final-gradebook` **200**、约 **22ms**、`labStatus=UNAVAILABLE`、`totalScore=null`。记录：`docs/吴本昭/2026-09-02/raw/api-smoke.log`。

### W0-4 关掉单体作业双跑（P0）

`backend/src/index.ts` 默认不再 `register` 作业三条路由（`MONOLITH_HOMEWORK_ROUTES=1` 才打开，方便对照）。作业流量只经网关 → `:3002`。
