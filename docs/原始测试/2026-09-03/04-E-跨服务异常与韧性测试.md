## 结论

跨服务的正常、权限、参数、下游不可用/超时和空结果均有对应的自动化验证。运行时基线复验通过 2/2；下游不可用和超时使用服务边界的可控 mock/超时单测验证，避免用真实故障测试污染业务数据。受控停服脚本会在 `finally` 中恢复作业服务副本数，并在调用端连接可能复用时重启调用端后再检查。

## 异常与边界覆盖

| 调用方向 | 场景 | 自动化证据 | 期望与结论 |
| --- | --- | --- | --- |
| Course → Homework/Lab | 正常聚合 | `E2E-MS-01`、`course-service/tests/upstream-summary.test.mjs` | Dashboard 聚合成功，依赖状态 `OK`。 |
| Course → Homework/Lab | 上游未配置、HTTP 失败或超时 | `course-service/tests/upstream-summary.test.mjs` | 统一返回 `UNAVAILABLE`，超时标为 `TIMEOUT`，不会把数据伪造为 0。 |
| Homework → Course | 课程服务超时、401 或 503 | `homework-grade-service/tests/course-access.test.ts` | fail-closed：写/读操作返回稳定 503，不把不可用误判为未选课。 |
| Homework → Lab | Lab 不可用、超时、空成绩 | `homework-grade-service/tests/lab-timeout.test.ts`、`gradebook.test.ts` | 总分保持 `null`，保留 provisional score，不把缺失实验成绩视为 0。 |
| Lab → Course | Course 返回 503 | `lab-practice-service/src/app.test.ts`、`practice-routes.test.ts` | 对外返回 `503 / COURSE_UNAVAILABLE`，并携带 Request-ID。 |
| Gateway → Homework | 下游不可用 | `api-gateway/src/index.ts`、`scripts/qa/cross-service-resilience.mjs` | Gateway 映射为 `502 / BAD_GATEWAY`，不暴露内部异常。 |
| 外部权限/参数 | 学生修改课程、访问管理端；非法选课时间 | `E2E-MS-02`、`E2E-MS-10` | 分别返回 403、403、参数校验错误；正常请求不受影响。 |

## 受控故障复现说明

```powershell
# 基线（不改动集群）
npm run qa:cross-service-resilience

# 受控停服（显式授权后执行）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/qa/run-cross-service-resilience.ps1 -InjectDownstreamFailure
```

受控停服命令只缩容 `homework-grade-service`，并自动恢复原副本数；为了避免 Kubernetes 终止中的 Pod 或 HTTP keep-alive 连接造成假阳性，脚本等待 Endpoint 与 Pod 均退出，并重启 Course、Gateway 调用端后才检查降级响应。执行期间不修改数据库数据。
