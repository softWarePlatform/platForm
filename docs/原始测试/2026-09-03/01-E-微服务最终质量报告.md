## 3. 跨服务集成与修复

本次真实 HTTP E2E 覆盖了 Course → Homework/Lab（Dashboard）、Homework → Course、Homework → Lab、Lab → Course 及 Gateway 路由。正常、权限、参数错误分支均被执行；运行时空结果复验为 2/2 PASS；服务不可用/超时的稳定响应由 Course、Homework、Lab 的独立契约测试覆盖。完整证据见 `04-E-跨服务异常与韧性测试.md`。

E2E 发现并修复一个真实缺陷：Lab 生成的中文通知幂等键被直接写入 HTTP header，Node fetch 因非 ASCII ByteString 抛出 500，导致 UC06 实验提交和 UC08 讨论提及失败。现通过 SHA-256 编码为 ASCII header 值；对应单测及复验均通过。实现见 `lab-practice-service/src/course-client.ts` 的 `notificationIdempotencyKey`。
