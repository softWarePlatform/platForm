测试条件、链路与有效性检查

所有展示数值均直接来自本轮原始 JSON，而不是人工估算

真实请求链路

单体：port-forward → Legacy API
微服务：port-forward → Web/Nginx → API Gateway → 业务服务

实际解析 URL

单体 /dashboard/me

微服务 /api/dashboard/me

单体 /courses/{courseId}/homework

微服务 /api/courses/{courseId}/homework

单体 /courses/{courseId}/lab-sets

微服务 /api/courses/{courseId}/lab-sets

有效性门槛

✓固定5个Worker，每个Worker顺序发送请求
✓HTTP成功且Content-Type为application/json
✓响应正文必须可解析为JSON
✓任一接口错误率超过0即判定失败

可比性控制

✓同一台Windows / Docker Desktop Kubernetes
✓单体、Gateway及业务服务均固定1副本
✓两侧分别创建1课程、1作业、1实验集、1实验题
✓使用课程ID定向查询，避免历史数据量污染
✓正式测试前每个接口预热10次
✓限流阈值在两侧等量提高，测试后恢复
